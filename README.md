# cinematic-prompt-master · 镜语

工种级 AI 提示词工程技能（**图像 / 视频一体，双平台一等公民**）：以 26 卷《AI 图像视频生成提示词·超细分主文档》为权威语料、以 atlas 图集为可填槽位词库，用「七层拼装法 + 三条翻译法则」把一句创意写成可直接投喂 **Seedance 2.0** 与 **MiniMax H3（海螺 Hailuo 3.0）** 的中英文提示词，并覆盖 MJ / SD / Flux / 可灵 / Veo / Sora 的语法壳迁移；交付固定为「先定妆块、后提示词块」的 text 代码块。

设计目标：**写得出具体、排得对顺序、锁得住人、站得住位、去得掉 AI 味、查得到词。**

## 为什么需要它

大多数人写提示词的失败不是"词不够高级"，而是五件事没做：

1. **顺序乱** —— 风格、主体、光学、片质混在一句里，模型只能随抽卡漂移。
2. **词是裸的** —— 写"电影感""高级""赛博感"，模型不认识这类抽象词，只认识载体、光学与笔刷。
3. **光学层缺失** —— 没有焦段（无透视）、没有光位（无立体）、没有片质（一眼 AI 味）。
4. **壳不对** —— 把 Seedance 的中文句式原样贴进 H3，字段名、时间戳、音轨全落空。
5. **站位漂** —— 多镜一镜一构图，第二镜人在左边、第三镜跑到右边，观众判定换人。

本技能把这五件事变成可执行的公式、查词库、平台语法壳与站位工程。

## 核心思路

### 一条公式：七层拼装

按此顺序排块，稳定性最高：

```text
[L1 风格母语] + [L2 题材套路] + [L3 时空天气]
+ [L4 主体(具名长相 + 动作)] + [L5 场景(构件 + 纵深 + 空间坐标)]
+ [L6 光学(焦段·景别·机位·光位·光比·屏幕侧位)] + [L7 调色 + 片质]
+ [L0 画幅/时长] − [负面]
```

| 层 | 缺了会怎样 |
|---|---|
| L1 风格母语 | 画风随抽卡漂移 |
| L2 题材套路 | 文化锚点缺失，出"四不像" |
| L3 时空天气 | 光感无依据、年代穿帮 |
| L4 主体 | 脸与身份随机漂移 |
| L5 场景 | 主体像贴纸贴背景上、站位无坐标 |
| L6 光学 | 无骨骼、无立体、无情绪落点、左右翻边 |
| L7 调色片质 | 一眼 AI 味 |
| L0 画幅负面 | 裁切错、手指崩、水印 |

排块口诀：**主体·场景·光·镜头·调·质**（L4→L7 的现场顺序；L1–L3 是总纲，永远在句首）。

### 三条翻译法则

| 法则 | 解决什么 | 怎么用 |
|---|---|---|
| **载体化** | 抽象风格词 | 三问拆解：记录介质是什么 / 光的脾气是什么 / 笔触肌理长什么样 |
| **光学化** | 情绪词 | 任意情绪落成至少一项：焦段 / 景别 / 机位高度 / 光位 / 光比 / 快门 |
| **介质化** | 画面"像什么拍出来的" | 句尾必须给一条介质背书（胶片型号 / 数码机 / 画纸 / 渲染引擎） |

典型翻译：

| 裸词（无效） | 可执行写法 |
|---|---|
| 电影感 | `anamorphic 2.39:1, anamorphic horizontal flare, soft highlight roll-off, 35mm fine grain` |
| 高级感 | `medium format, buttery highlight roll-off, open clean blacks with detail, restrained palette + one warm accent` |
| 复古港风 | `Kodak 500T pushed 1 stop, halation on neon, green-magenta cast, handheld` |
| 国风 | `xuan paper fiber tooth, bleeding ink edges, dry-brush flying-white, generous negative space` |
| 赛博 | `cyan-magenta dual-source, wet asphalt specular streaks, volumetric haze, sodium practicals as bokeh` |
| 3A 游戏 CG | `UE5 Lumen + Nanite, PBR roughness variation, screen-space reflections, sub-surface scattering` |

### 三个硬参数，缺一个就假

- **焦段** → 决定透视（85mm 立体压缩 / 24mm 空间纵深 / 广角贴脸压迫）
- **光位** → 决定立体（45° loop 日常 / 伦勃朗古典 / 侧逆脱离背景 / 底光恐怖）
- **片质** → 决定 AI 味（柔和高光滚降 + 有细节的黑 + 细颗粒三件套）

### 一张双平台矩阵

同一份语义母版，换壳不换词：

| | Seedance 2.0 | MiniMax H3 / 海螺 3.0 | 通用英文系 |
|---|---|---|---|
| 语言 | 全中文 | 中英皆可，段名与标签英文 | 英文为主 |
| 结构 | 一段散文 + 时间戳 | **六段式** `subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music` | 一段散文 |
| 引用 | `@图片1`…`@图片9`，合计 ≤12 | **`<Subject N>` / `<Picture N>`**，按上传槽位；9 图 / 3 视频 / 3 音频 / 合计 12 | MJ `--sref` / SD ControlNet |
| 运镜 | 中文自然句 | **`Push In with small amplitude at slow speed`**（或方括号） | `slow dolly in` |
| 时间 | `0-3s：…` | **`[Shot 1]` 不带时间 + `At 00:04.000,`** | 段落叙述 |
| 台词 | 引号 + 角色 | **`<Subject N> (Sx) says, <d>[Chinese] …</d>`** | 引号 + 说话人 |
| 音频 | 单独「音效/台词」行 | **`overall_soundscape` + `non_diegetic_music`**（音色参考走 `<Audio N>`） | 多数无音轨 |
| 负面 | 独立负面块分域 | **无负面字段 → 保留契约 + `Avoid`** | MJ `--no` / SD 负面框 |
| 时长 | ≤15s | 4–15s，默认 6s，2K/768P、24fps | Veo/Sora 5–8s |

## 主文档主导：一部语料，四种读法

仓库内置 26 卷、566,313 字节、7626 行的原版语料：[`master/AI图像视频生成提示词_超细分主文档.md`](master/AI图像视频生成提示词_超细分主文档.md)，以及它的可填槽位视图 [`master/prompt-atlas.json`](master/prompt-atlas.json)（370KB）。

- **主文档 = P0 权威**：所有具名词、参数、范例、负面词以它为准。
- **`references/01–11` = P1 速查卡**：压缩、表格化、可随手抄；与主文档冲突时听主文档。
- **atlas = P1.5 可填词库**：279 个叶子槽位、7400+ 枚举候选，中英并列；只给候选词，句子仍回主文档。
- **`references/12–13` = P2 结构与工程**：H3 语法壳、站位轴线；结构听它，词回 P0/P1。
- 自创词（P3）允许，但必须具名可验证并标 `[自创]`，占比 ≤ 20%。

取词三步：**查索引定位卷 → 取原文原句 → 抄不到就降级为可验证物理描述**。禁止凭印象编具名词。

```powershell
# 主文档：26 卷总目录 / 卷内小节 / 关键词取原句
.\scripts\lookup-master.ps1 -Outline
.\scripts\lookup-master.ps1 -Outline -Volume 20
.\scripts\lookup-master.ps1 -Query "Rembrandt","伦勃朗" -Context 1

# atlas：分卷总览 / 某槽位全部候选 / 全库模糊搜（多词逗号合并）
.\scripts\atlas-lookup.ps1 -Outline
.\scripts\atlas-lookup.ps1 -Path "摄影层/焦段镜头"
.\scripts\atlas-lookup.ps1 -Query "推近,dolly,环绕"
```

两个脚本只依赖 PowerShell 自带能力，Windows PowerShell 5.1 与 pwsh 7 都能跑；输出为 命中标题 + 行号 + 上下文 / 路径 + 候选选项。

## 提示词升维：60 分改到 90 分

优化不是"再加点形容词"，加词只会更糊。技能内置一套**六维体检 + 五级手术**：

| 维度 | 5 分标准 |
|---|---|
| 主体辨识 | 具名长相段 + 标志物 + 状态（3–5 项形，色锁死） |
| 光学具体 | 焦段 + 景别 + 机位 + 光位 + 光比，至少三项 |
| 介质可信 | 具名介质 + 颗粒/滚降/色域，可被摄影指导复现 |
| 空间站得住 | 固定物坐标 + 纵深层次 + 比例锚 |
| 时间有推进 | 起—中—止 + 环境反应 + 可见变化量 |
| 词库可溯源 | 每个专名能回主文档卷号，或已标 `[自创]` |

满分 30，交付线 26。五刀顺序：**拆裸词 → 落光学 → 补介质 → 补因果 → 收预算**；砍完掉分的那句是承重句，必须加回去。

## 站位工程（多镜必修）

**三个独立变量，只锁一个必漂**：空间实位（距哪个固定物多远，进 L5）、屏幕侧位（本机位下谁在画面哪边，进 L6）、机位（在哪、多高、朝哪、什么景别，进 L6）。

四条硬规则：

1. 坐标只用固定物（停止线、第 N 条白线、缘石、门框、桌沿、台阶第几级）；删掉所有"左右前后"后位置仍唯一才算合格。
2. 同场不越轴：机位只在轴线一侧，相邻机位夹角 ≤90°、高度差 ≤ 一个身位、景别不连跳两级。
3. 侧位逐字复用：`X 在画面左侧` 全组照抄；反打成对，下一镜切回原侧位。
4. 首尾态逐字接力：第 N 镜末态 = 第 N+1 镜首态，五项必落字（位置、朝向、动作相位、接触点、表情强度）。

单图/单镜用轻量三句式：`空间锚 + 屏幕侧位 + 比例锚`。全套见 [`references/13-staging-and-axis.md`](references/13-staging-and-axis.md)。

## 交付契约（固定顺序）

先给 `【定妆】` 块（角色、场景、站位的一致性锁，逐项写死），再给 `【提示词】` 块；两块一律用 `text` 代码块包裹，块内只留可直接复制的文本，解释写在块外。

MiniMax H3 的提示词块结构不同，六段段名与尖括号标签逐字保留：

```text
【上传对照】
<Picture 1> = 传什么｜校验：…

【提示词 · MiniMax H3】
subject_definitions:
<Subject 1> is the … in <Picture 1>, with …

summary:
[reference generation] …

retention_analysis:
<Subject 1> (appears in [Shot 1], [Shot 2]): fully_preserved - …
<Picture 1> ([Shot 1] 到 [Shot 2]): fully_preserved - 多视图只锁定同一个人，不把三视图排进画面。

detailed_description:
整体风格一句。
[Shot 1] …
[Shot 2] At 00:04.000, …
<Subject 1> (S1) says, <d>[Chinese] 台词</d>

overall_soundscape:
…

non_diegetic_music:
N/A
```

定妆面板 / 三视图已经出图时，`【定妆】` 块退化为上传对照表：不重写长相，只写槽位、校验点和 `<Subject N>` 的 1–2 句锚点。

## 质检清单（交付前逐条过）

- 出现"电影感/高级/唯美/氛围感/赛博感"等裸词了吗？→ 已载体化
- L4 主体 / L6 光学 / L7 片质三层有没有空
- 焦段、光位、片质三件套齐不齐
- 情绪词是否落成了光学参数
- 六维体检 ≥26 分，承重句一句没删
- 视频：每段有运镜 + 可见变化量 + 音效，分镜覆盖完整时长
- 视频：物理一致性条款 ≥2 条；@ 引用与素材清单一致；素材 ≤12；未含写实真人面部
- H3：三字段名逐字正确、时间戳累加等于总时长、方括号 ≤3 线索、台词有说话人与秒数、全文 ≤2000 字符
- 锁人：描述块原样复用 + 三视图/参考图 + seed + 负面兜底 四件套齐
- 多镜：蓝图删掉左右仍唯一、侧位未翻、首尾态逐字接力、每镜有可见变化量
- 负面词分域（人体/结构/文字水印/画质/画风）至少 3 域
- 字数在预算内，形容词已砍两轮
- 具名词可回溯：每个专名能在主文档找到出处，或已标 `[自创]`
- 同一概念只用一种说法，没有同义词并列

## 平台硬规则

**Seedance 2.0**

1. 提示词全中文（含图片生成提示词）。
2. @ 引用必须官方命名：`@图片1`–`@图片9`、`@视频1`–`@视频3`、`@音频1`–`@音频3`。
3. 不得含写实真人面部素材（平台自动拦截）。
4. 混合素材上限 12 个（图 + 视频 + 音频合计）。
5. 单次生成 ≤15 秒，超出走分段 + 延长。

**MiniMax H3**

1. 六段段名逐字写、不翻译、不调序：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`。旧镜像只认三段式时用 `integrated_multimodal_description` 顶替（见 `references/12` 第十六节）。
2. 标签用尖括号：`<Subject N>`（可反复引用的可见内容）/ `<Picture N>` `<Video N>` `<Audio N>`（按上传槽位）/ `[Shot N]`。
3. 台词三块挨一起：`<Subject N> (Sx) says, <d>[Chinese] 台词</d>`；(Sx) 按本组开口顺序，不跳号不倒序，齐声用 `say`。
4. 配额：9 图 / 3 视频 / 3 音频 / 合计 12；单段 ≤15 秒、同类合计 ≤15 秒；音频不能单独使用。
5. prompt ≤2000 字符；4–15 秒；2K/768P；24fps。
6. 第一镜 `[Shot 1]` 不带时间戳，后续 `At 00:04.000`；运镜英文句式或方括号二选一，单镜 2–3 个线索。
7. 没有负面字段：禁止项写成保留契约 + 一句 `Avoid`；不要写 "no music"，不需要配乐写 `N/A`。
8. 要精确控制结构时设 `prompt_optimizer: false`。

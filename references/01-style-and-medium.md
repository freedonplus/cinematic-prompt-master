# 01 · 风格母语 / 记录介质 / 片质基调

> **本册用途**：解决 L1（风格母语）与"这句风格词到底该换成什么词"。
> 心法：**载体锁年代，片种锁情绪，作者锁语法，介质词锁笔触。** 四者齐下，才能稳定还原脑中的那一帧。

---

## 一、记录介质（决定"画面被什么拍下来"，最强的一张表）

| 中文 | 英文 | 画面效果 | 可抄写法 |
|---|---|---|---|
| 胶片 | Film / Analog | 颗粒、宽容度大、高光柔和、青或暖偏色 | `35mm film photograph, grain, analog color` |
| 数码 | Digital | 干净锐利、零颗粒、色彩准确到发干 | `digital photograph, ultra sharp, clean` |
| 黑白胶片 | B&W Film | 中灰层次、银盐颗粒（非数字噪点） | `black and white film, silver halide grain` |
| 拍立得 | Instant Film | 白边、低对比偏冷、暗角、略糊 | `Polaroid instant photo, white border, faded` |
| 中画幅 | Medium Format | 立体强、奶油焦外、油润细腻 | `medium format, creamy bokeh, tonal smoothness` |
| 大画幅 | Large Format | 移轴校正、极细腻、全景深感 | `large format 4x5, view camera, tonal depth` |
| 微距 | Macro | 极浅景深、金属高光、微观纹理 | `macro 1:1, extreme close-up, micro texture` |
| 长曝光 | Long Exposure | 水拉丝、车流光轨、云层流动、水面镜平 | `long exposure, silk water, light trails` |
| 双重曝光 | Double Exposure | 半透明人像嵌景物 | `double exposure, silhouette blended with landscape` |
| 红外 | Infrared | 树叶雪白、天空近黑、诡异通透 | `infrared, white foliage, dark sky` |
| 移轴 | Tilt-Shift | 焦平面可倾斜；配高机位=微缩模型 | `tilt-shift, miniature effect, selective focus` |
| 柔焦 | Soft Focus | 高光晕染、朦胧 | `soft focus, dreamy halo, glow on highlights` |
| 老照片 | Vintage | 泛黄、划痕、褪色、暗角、重颗粒 | `vintage photograph, sepia, scratches, faded` |

## 四、作者参考的"翻译"用法（别只写名字）

**写法公式：`名字 → 四维（光/色/构图/运动）→ 具体词`**

| 参考 | 该落成的词（而不是只写名字） |
|---|---|
| 王家卫 | 霓虹溢色、慢门拖影、手持微晃、抽帧、绿红双色偏向 |
| Roger Deakins | 单光源低照度、冷暖对撞、静默长镜、光比 4:1 以上 |
| Villeneuve | 巨构压迫、单体置于画面下缘、雾与体积光、极简色板 |
| Nolan | 高对比自然光、IMAX 大远景、无 CG 感的实拍灰阶 |
| Wes Anderson | 正中对称、平面化配色、章节式构图、定格凝视 |
| Fincher | 冷绿低饱和、精密构图、硬光小光比控制、干净黑场 |
| 莫奈/印象派 | 破碎笔触、色温变化代替轮廓线、柔和边缘 |
| 国画工笔 | 铁线描、矿物色层染、绢本、留白 |
| 水墨写意 | 皴擦笔、墨分五色、飞白、大量留白 |

> **反例**：`王家卫风格` → 无效。
> **正解**：`Kodak 500T pushed 1 stop, neon halation, handheld sway, step-printed frame jumps, 35mm grain, green-magenta cast`。

## 五、三叠法（最快出一条合格 L1）

```
【介质/格式】+【片种/题材】+【作者语法】+【光照时段词】
```

四条范例：
- `35mm Kodak 500T film, film noir venetian blinds, Deakins low-key lighting, rain-slicked night street`
- `ARRI ALEXA, cyberpunk neon cyan-pink, Villeneuve vast composition, volumetric rain fog`
- `Ilford HP5 b&w, street decisive moment, Wong Kar-wai handheld sway, overcast soft light`
- `Super 8 home footage, gothic horror, candle chiaroscuro, vintage desaturation`

## 八、风格失败的三类症状 → 修法

| 症状 | 病因 | 修法 |
|---|---|---|
| 一会儿胶片一会儿 CG | 只写了风格名，没锁介质 | L1 换成具体介质 + 片质词（表一、表六） |
| 文化锚点错（和风写成中式） | 只写"古风" | 换成具名形制词（见 02 册） |
| 全画面"塑料" | 缺片质层 | 加"柔和高光滚降 + 有细节的黑 + 细颗粒"三件套 |

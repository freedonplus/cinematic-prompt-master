# 07 · 运镜 / 速度 / 表演动作 / 长视频分段

> **本册用途**：视频类任务的 L6 与"动"的语法。视频提示词 = **运镜的选择 + 动作的序列 + 物理的声明**。
> 核心认知：**镜头在动 = 视线在移动 = 观众注意力被引导。** 运镜不是装饰，是叙事。

---

## 一、运镜大全

| 运镜 | 英文 | 定义 | 情绪/作用 |
|---|---|---|---|
| 固定 | locked / static | 机位不动 | 冷静、凝视、压迫、纪实 |
| 推近 | push in | 前推，主体变大 | 渐进强调、逼近、紧张 |
| 拉远 | pull out | 后拉，环境显现 | 揭示、结束感、孤独渺小 |
| 横摇 | pan | 原地左右转 | 跟随横向移动、扫视 |
| 纵摇 | tilt | 原地上下转 | 揭人物/显全貌 |
| 前移机 | dolly in | 机位整体前移（有透视，区别于变焦） | "走进场景"感 |
| 后移机 | dolly out | 机位整体后退 | 拉开、疏离 |
| 横移机 | tracking / truck | 平行于被摄体平移 | 跟行、卷入感 |
| 环绕 | orbit / 360 | 绕主体画弧 | 强调、眩晕、揭示多面、主宰感 |
| 升降 | crane / jib | 摇臂整体升降 | 上帝视角揭示、盛大 |
| 手持 | handheld | 机手持拍（见下三档） | 真实、焦虑、临场 |
| 稳跟 | steadicam | 稳定器跟人 | 流畅、亲密、纪实 |
| 甩镜 | whip pan | 快速甩过、画面虚成色带 | 转场、速度、焦躁 |
| 变焦 | zoom | 光学缩放、透视不变 | 强调细节/快速拉远 |
| 希区柯克 | dolly zoom / vertigo | 前移同时变焦拉远、背景"挤过来" | 惊悚、眩晕、心理崩溃 |
| 航拍 | drone / aerial | 高空 | 揭示全貌、壮阔 |
| 第一人称 | POV | 镜头即角色眼睛 | 沉浸、临场 |
| 转场机位 | transition shot | 专为衔接下镜设计 | 运镜无缝 |

### 手持三档（晃动是"信息"，不是失误）
| 档 | 英文 | 情绪 | 写法 |
|---|---|---|---|
| 微晃 | subtle handheld | 纪录片真实、去塑料感 | `subtle handheld breathing, barely-there movement` |
| 中晃 | moderate handheld | 追逐、焦虑、情绪不稳 | `moderate handheld shake, nervous energy` |
| 狂晃 | heavy shaky | 狂躁、暴力、混乱 | `violent shaky handheld, chaotic aggressive` |

### 速度与幅度（别只说"快/慢"，给参考）
速度：`glacial 极缓 / slow / steady / gradual / fast / rapid`
幅度：`tiny 微幅 / subtle 小幅 / moderate 中幅 / sweeping 大幅 / wide arc 全景弧`
> `glacial 180-degree orbit in a wide sweeping arc around the subject`
> `机位以一个呼吸般的节奏缓缓推近，最终定格在人物双眼`

### 组合技（一次最多 2–3 个，用 `+` 连）
`Orbit + Zoom In` / `Crane Up + Pan` / `Dolly Back + Tilt Up` / `Push In + Dutch Angle`

### 镜头质感修饰（隐藏层级，最出大制作感）
`雾水珠附着镜头前` / `雾粒粘镜` / `镜头轻微抖动` / `镜头畸变 + 雾层折射` / `轻微光晕 halation` / `镜头脏污产生的柔焦光斑`
> 这些"不完美"反而大幅提升真实感，是区分普通与大制作的关键细节。

## 二、速度的写法（三件套，比"very fast"有用一百倍）

速度 = ① 主体自身形态（清晰肢体 → 轮廓模糊 → 纯光带）② 背景后掠量（静止 → 轻微视差 → 强烈拖尾）③ 介质被扰动程度（无 → 发丝轻扬 → 烟尘喷涌 → 冲击波）。

| 档 | 可抄写法 |
|---|---|
| 静止 | `dust motes motionless, flag hanging limp without a ripple` |
| 极缓 | `dust settling so slowly it seems frozen, shadow crawling imperceptibly` |
| 徐缓 | `smoke oozing lazily across the ground` |
| 慢 | `a slow deliberate saunter, paper drifting down slowly` |
| 适中 | `at normal walking pace` |
| 轻快 | `moving at a brisk purposeful pace` |
| 快 | `sprinting past, water rushing downstream` |
| 疾迅 | `a swift blur of motion` |
| 疾驰 | `tearing through the frame, scenery streaking backward` |
| 风驰 | `the object reduced to a streak of light` |
| 冲击波级 | `a cone of compressed air distorting the light ahead of it` |

### 步行三速区分（治"所有走都一个样"）
| 档 | 下肢 | 躯干 | 摆臂 | 发/衣 |
|---|---|---|---|---|
| 疾走 | 步幅 ~90°、前掌先落贴地 | 前倾 ~5° | 摆动小、肘贴身 | 发丝微摆、衣摆轻晃 |
| 小跑 | ~110°、短暂离地屈膝 | 前倾 ~15° | 肘屈 90° 前后摆 | 发丝后甩、衣摆飘起 |
| 狂奔 | ~140–160° 大开大合、前膝高抬 | 前倾 30–45° 俯身前扑 | 摆臂猛、拳握紧 | 发丝水平后飘、衣摆猎猎 |

## 三、时间与速度感（同一动作，改速度就改情绪）

| 效果 | 写法 | 用途 |
|---|---|---|
| 轻升格 | `light slow-motion, the arc of her hair clearly visible` | 柔顺、仍有惯性 |
| 重升格 | `extreme slow-motion, each raindrop a suspended sphere, every strand of hair floating` | 唯美、重量感 |
| 子弹时间 | `bullet time: time frozen as the camera orbits, droplets crawling through the air` | 英雄时刻 |
| 时间冻结 | `a single frozen moment, splashes suspended, even the dust stopped dead` | 定格海报 |
| 变速 | `speed ramp from slow motion to real time` | 呼吸节奏 |
| 快进/延时 | `time-lapse of clouds boiling, car lights streaking into trails` | 时间压缩 |
| 逆放 | `playing in reverse, backward motion` | 梦境/回溯 |
| 凝滞感 | 主体与镜头双静止，**只动光**：`the sunbeam creeping across the room while everything else stays motionless` | 表达"时间在走"最高级手法 |

## 四、动作质感词（先定基调，再写序列）

`explosive 爆发力（蓄劲→弹起→残影）` / `fluid 流畅（如水淌过、一气不停顿）` / `rigid 僵硬（关节锁定、提线木偶）` / `limp 绵软（断线般软倒）` / `agile 敏捷（小碎步连点、掠水燕子）` / `grounded 沉稳（扎马沉腰、脚碾沙石）` / `light 轻盈（点水仅涟漪）` / `staggering 踉跄（后退两步才站定）` / `shaky 颤抖（刀尖寒芒抖动）` / `decisive 果决（路径最短、不顿挫）` / `hesitant 迟疑（举拳又放下）`

## 五、物理一致性条款（AI 视频第一崩点）

| 崩点 | 必写条款 |
|---|---|
| 手指 | `natural relaxed hands, five fingers well-formed, no distorted fingers` |
| 肢体折叠 | `movement within real joint limits, no interpenetrating limbs` |
| 发/衣穿体 | `strands swaying with the head turn but never intersecting the face; cloth obeying gravity` |
| 重心 | `stable center of gravity, natural weight shift` |
| 环境无反应 | `as she steps, fine dust lifts off the ground` / `fingertip trails the water, concentric ripples spreading` / `dappled shadows shift across her face as she moves` |
| 动作僵硬 | 拆「起—中—止」，用 `先…再…最后…`（`she walks forward, stops mid-step, then slowly turns her head`） |
| 总纲 | `movement obeys real gravity and momentum, objects rebound physically on impact` |

## 六、打斗编排（四段闭环）

**静（起势）→ 动（交锋）→ 失衡（受击）→ 静（收势）**，节奏由缓到骤再归于凝滞。

| 阶段 | 必须给什么 |
|---|---|
| 起势 | 姿态（guard/bow/empty）+ 重心（前/后腿）+ 兵刃位置 + 目光锁点 |
| 交锋 | "先→再→随后"的因果链：垫步 → 拧腰送力 → 攻向要害 |
| 受击 | 受力点 + 后退方向 + **缓冲**（拄地/犁痕/踉跄几步） |
| 收势 | 回到静态姿态定格，形成闭环（垂剑/收刀/粗重呼吸） |

**封装模板（英，直接填）**
```
[Stance]: {fighter} adopts a {guard/bow} stance, weight on {rear/front} leg, {weapon} positioned at {spot}, aimed at {target}.
[Attack]: {fighter} first {skip-step} forward, {torso rotation} drives {thrust}, aimed at {vital point}.
[Counter]: {opponent} {parries with the spine of the blade / sidesteps}, redirecting it off-line, then {follow-up}.
[Reaction]: {hit fighter} takes the strike at {body part}, body {reels back N steps}, {boots plowing furrows} to absorb momentum.
[Closer]: {winner} {sheathes / lowers blade} into {final stance}, {hurt fighter} steadies on {support}, both return to a still standoff.
```
> 每段必含"重心转移 + 反作用力 + 缓冲"，才有物理一致与叙事完整。

## 七、一镜到底

**写法要点**：按**空间顺序**连续写"机位动作 + 被摄体动作"，用"然后/接着/最终"串，并反复强调 `single continuous take / one-take / unbroken / no cut`。

> 示例：`一个一镜到底的镜头：从街道上空缓缓下降切入，跟随撑伞女子穿过雨巷，她停步回望，镜头绕到她前方，继续推进穿过拱门，一气呵成无剪辑`

## 八、镜头组接与节奏（多镜任务必写）

| 组接 | 英文 | 用法 |
|---|---|---|
| 硬切 | hard cut | 干脆、冲击 |
| 叠化 | dissolve | 时间流逝、回忆 |
| 淡入淡出 | fade in/out | 起止、段落 |
| 甩接 | whip-pan cut | 快速、时间跳切 |
| 匹配剪辑 | match cut | 隐喻、视觉诗意 |
| 跳切 | jump cut | 急促、时间省略 |
| 动作顺接 | cut on action | 让剪辑"隐形" |
| J/L-cut | J-cut / L-cut | 声音先行/声音延续 |

节奏总纲一句话：`整体先舒缓后骤然加快，开场长镜铺陈，高潮密集快剪与甩接卡点，结尾黑场淡出`。

## 九、分镜写法（每镜五要素）

`镜号｜景别｜机位/运动｜画面内容（动作+表情+光+环境）｜时长`，切换处补 `衔接：硬切/叠化/正反打/动作顺接`。

**验收线**：每格必须写出**相对上一格的变化量**——接触点 / 位移 / 相位 / 可视结果。没有变化量 = 两格是同一格，等于废镜。

## 十、硬参数（决定"能不能出片"）

| 参数 | 写法 | 说明 |
|---|---|---|
| 时长 | `5 seconds, 10-second clip` | 越长越难保一致 |
| 帧率 | `cinematic 24fps` / `smooth 60fps` | 电影感=24fps |
| 循环 | `seamless loop, loop perfectly` | 动态壁纸/转场 |
| 首帧 | `start from this first-frame image` | 锁开头 |
| 尾帧 | `end on this last-frame image` | 锁结尾 |
| Seed | `fixed seed for consistency` | 跨次稳定 |
| 运动幅度 | `strong motion` / `gentle subtle movement` | 幅度面板 |

## 十一、>15 秒：分段 + 延长（必须做，别硬写）

**规则**：单次 ≤15s。超出走「分段生成 + 视频延长拼接」。

**每段必须写"衔接点"三件**：① 前一镜最后一帧的**构图**（主体在画面哪个位置、占多少）② **动作相位**（动作停在哪一刻：剑刚出鞘半寸/手指将触未触）③ **光源位置与色温**（光从哪边来，贵在接得上）。

**分段模板**
```
【第1段 0-15s】[品质锚定][氛围][分镜]… 末帧定格：主体居中偏左，剑出鞘半寸，逆光在右侧
【第2段 延长10s】将@视频1延长10s，延续末帧构图：主体保持居中偏左，剑完全出鞘，右侧逆光延续，新增：跃起劈下
```

**三条防断招**
1. 每段开头重复一次"大气连贯声明"（同一雾/同一雨/同一色调），防氛围断裂。
2. 每段都重复角色的"固定描述块"，防换脸。
3. 段落之间留一个**动作相位重叠**（后段前 1 秒重演前段最后 0.5 秒），接得上才不跳。

## 十二、视频负面（每次必带）

`no extra fingers, no fused limbs, no morphing face, no flickering, no warping background, no sudden camera jumps, no text or watermark, no frame tearing, no inconsistent light direction, no rubber-like motion, no liquid stretch artifacts`

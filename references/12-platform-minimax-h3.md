# 12 · MiniMax H3（海螺 Hailuo 3.0）语法壳与实操规范

> **本册用途**：把七层拼装出来的语义母版，套进 H3 的语法壳，直接投喂可跑。
> **定位**：与 Seedance 2.0 语法壳（见 `10-platform-and-negative.md`）并列的双平台矩阵。
> **核心认知**：H3 是「结构化字段 + 方括号运镜 + 时间戳切片」三件套驱动的模型。散文写表演，结构写机器，两套系统各管各的，混着写必崩。

---

## 一、平台硬指标（先守约束，再谈创意）

| 项 | 规格 | 超限会怎样 |
|---|---|---|
| 分辨率 | 2K / 768P 两档 | 想要 1080P 中间档没有，商业出片直接选 2K |
| 帧率 | 24fps | 电影感自带，不用在提示词里写帧率 |
| 时长 | 单次 4–15 秒，默认 6 秒 | 不写时长就给 6 秒，节奏会被掐断在半截 |
| 音频 | 原生立体声 + 对白，音画同步生成 | 后期配音不必，台词直接写进提示词 |
| 提示词上限 | 2000 字符 | 超长会被截断，截断处之后的镜头直接丢失 |
| 参考素材上限 | 9 图 + 3 视频 + 3 音频，合计 12 | 第 13 个素材静默丢弃，引用落空 |
| prompt_optimizer | 默认开启 | 想精确控制每个字段与方括号时必须手动设 `false`，否则模型会改写你的结构 |

**两条铁律**：
1. 要精确控制 → `prompt_optimizer: false`。开了优化器，你写的字段名、时间戳、方括号都可能被模型重新组织，结构化写法等于白写。
2. 时长永远显式写。违反会怎样：默认 6 秒，你设计的三段节奏被硬裁成两段。

---

## 二、五种模式选择表（先判模式，再动笔）

| 模式 | 输入什么 | 提示词第一职责 | 最容易崩在哪 |
|---|---|---|---|
| **T2VA** 纯文生 | 只有文字 | 用散文把主体长相、场景、光位全部立起来 | 没图兜底，主体长相写得虚就随机换人 |
| **I2VA** 首帧 | 一张图当起点 | 保留首帧身份，只写「从这一帧之后发生什么」 | 重描服装与首帧打架，像素级烧掉脸 |
| **FL2VA** 首末帧 | 首帧 + 末帧两张图 | 写清首末之间的路径（怎么从 A 走到 B） | 只写起点终点不写过程，模型硬切跳变 |
| **L2VA** 只给末帧 | 一张图当终点 | 写清「画面如何运动到这个终态」 | 生成段与末帧构图对不上，结尾生硬拼接 |
| **Ref2VA** 多参考 | 图/视频/音频混合参考 | 逐个定义参考的角色与用途 | 参考没定义槽位，模型猜错谁是谁 |

**判断口诀**：有起有止 FL2VA，只要起点 I2VA，只要终点 L2VA，什么都没有 T2VA，一大堆素材 Ref2VA。

## 三、基础三段式骨架（T2VA / I2VA / FL2VA / L2VA 通用）

字段名逐字准确，全小写下划线：

```text
integrated_multimodal_description:
[Shot 1] ...
[Shot 2] At 00:04.000, ...
overall_soundscape: ...
non_diegetic_music: ...
```

| 字段 | 装什么 | 不许装什么 |
|---|---|---|
| `integrated_multimodal_description:` | 全部画面内容：风格、主体、场景、光、`[Shot N]` 时间线 | 不装台词（台词放画面行内引号）、不装配乐描述 |
| `[Shot N]` | 每个镜头一段：景别、运镜方括号、主体动作、台词 | 一个 Shot 不许塞三个以上动作 |
| `At 00:04.000,` | Shot 内的节拍切分点 | 不许切片时长加起来 ≠ 总时长 |
| `overall_soundscape:` | 现场声：环境底噪、脚步、衣料摩擦、呼吸、撞击 | 不许复述完整台词——台词已在画面行内，复述等于触发两次生成 |
| `non_diegetic_music:` | 观众听得到、画内没有声源的配乐 | 画内音源（收音机、街头乐器、电视）不写这里，放回 `overall_soundscape` 或对应 Shot 的时间线 |

**三条硬规则**：
1. 字段顺序固定：画面在前，音轨在后。违反会怎样：模型把声音描述混进画面，生成字幕后叠影。
2. 配乐只写观众耳朵里的。违反会怎样：画内音源写成配乐，画面里凭空出现乐器和喇叭。
3. 每个 `[Shot]` 至少一次可见变化量（接触点/位移/相位/可视结果）。违反会怎样：整镜像会动的照片。

## 四、Ref2VA 六段式骨架

字段名逐字准确，顺序固定：

```text
subject_definitions: ...
summary: ...
retention_analysis: ...
detailed_description: ...
overall_soundscape: ...
non_diegetic_music: ...
```

每段一句职责 + 短示例：

| 字段 | 职责 |
|---|---|
| `subject_definitions` | 给每个参考素材定身份：图 N 是谁/是什么、视频 N 复刻什么、音频 N 当什么用 |
| `summary` | 一句话讲清整支片讲什么 |
| `retention_analysis` | 声明哪些属性必须保留（脸、服装、版型、配色、构图） |
| `detailed_description` | 分 Shot 写画面时间线，运镜用方括号 |
| `overall_soundscape` | 现场声三件：环境底噪 + 动作声 + 与参考音频的对接方式 |
| `non_diegetic_music` | 观众听得到的配乐；不需要写 `N/A` |

**短示例**：

```text
subject_definitions: 图1是女主角的定妆照（参考她的脸与发型），图2是场景氛围图（参考色调与光位），视频1提供运镜节奏。
summary: 女主角在雨夜巷口收伞回眸，镜头推进至面部特写。
retention_analysis: 保留图1的脸型、眉眼、黑色短发与米色风衣版型；保留图2的青橙色调与右侧霓虹光位；不保留视频1的画面内容，只保留其推进速度。
detailed_description: [Shot 1] At 00:00.000，雨夜巷口，女主角收伞甩水，[Push in]，伞尖水珠落地溅开。At 00:04.000，[Push in]继续，她缓慢回眸看向镜头，霓虹在右颊打出橙色轮廓光。
overall_soundscape: 持续雨声，伞面收拢的布料摩擦声，水珠落地，她的呼吸声随回眸变重。
non_diegetic_music: N/A
```

**铁律**：`retention_analysis` 必须写「不保留什么」。违反会怎样：模型把参考视频的画面内容也搬进来， 出四不像缝合。

## 五、方括号运镜指令（机器精度层）

15 条中英对照，方括号内用英文：

| 中文 | 方括号写法 |
|---|---|
| 推进 | `[Push in]` |
| 拉远 | `[Pull out]` |
| 左移 | `[Truck left]` |
| 右移 | `[Truck right]` |
| 左摇 | `[Pan left]` |
| 右摇 | `[Pan right]` |
| 上升 | `[Pedestal up]` |
| 下降 | `[Pedestal down]` |
| 上摇 | `[Tilt up]` |
| 下摇 | `[Tilt down]` |
| 变焦推近 | `[Zoom in]` |
| 变焦拉远 | `[Zoom out]` |
| 晃动 | `[Shake]` |
| 跟随 | `[Tracking shot]` |
| 固定 | `[Static shot]` |

**三条硬规则**：
1. 一个方括号内最多 3 个指令，逗号分隔 = 同时发生。违反会怎样：指令互相抵消，镜头瘫在原地。
2. 多个方括号按出现顺序依次生效。违反会怎样：先推后摇写成同段乱序，运镜轨迹糊成一团。
3. 全片每个镜头总共只留 2–3 个运动线索。违反会怎样：背景抖动、纹理闪烁、地面网格扭动。

**方括号与自然语言的分工**：
- 方括号管机器精度：方向、幅度、时机。`[Push in]` 就是推，模型不需要猜。
- 散文管表演与情绪：`她缓慢地、像不忍惊动什么似的回过头`。表演永远不写进方括号。
- 判定标准：这句话删掉后镜头轨迹变不变？变 → 方括号；不变 → 散文。

## 六、时间戳写法规范

格式：`At 00:04.000,`，秒后必须三位小数。

```text
[Shot 1] At 00:00.000，...；At 00:04.000，...
```

**三条硬规则**：
1. 切片累加必须等于总时长。设 8 秒就切到 00:08.000 收口。违反会怎样：尾部空转或硬断。
2. 单镜 ≤15 秒内至少 2 个时间 beat。违反会怎样：模型把一个动作均摊到全时长，爬成慢动作。
3. 每个 beat 写「该时刻画面长什么样」，不写「然后过了几秒」。违反会怎样：模型自由分配时间，节奏失控。

**beat 设计口诀**：起（00:00 状态）→ 变（中段动作相位）→ 收（末态定格）。三拍最稳。

## 七、音频三轨法

| 轨 | 写在哪 | 装什么 | 硬规则 |
|---|---|---|---|
| ① 台词 | 画面行内 | 引号包裹 + 标注说话人 + 给足秒数 | 长台词必须按 beat 切开分配；一句超过所在切片时长会被拦腰切断 |
| ② 现场声 | `overall_soundscape` | 环境底噪、脚步、衣料、呼吸、撞击 | 只写画内可溯源的声音 |
| ③ 配乐 | `non_diegetic_music` | 观众听得到的音乐 | 不需要就写 `N/A` |

**台词示例**：

```text
At 00:00.000，女主角（低声，克制）："你到底想瞒到什么时候。"
At 00:04.000，男主角（沉默两拍后，哑声）："我说不出口。"
```

**红牌规则：禁止写 "no music"**。否定式可能触发音频审核并污染整条音轨。
要么正向描述现场声（`只有雨声与她的呼吸`），要么写 `non_diegetic_music: N/A`。
违反会怎样：轻则音频静默，重则整条生成被拒。

---

## 八、屏幕文字规范

画面里要出现的字（招牌、手机屏、字幕条、包装文字）：

1. 逐字引号写出：`招牌上写着"陈记糖水"`。违反会怎样：模型造字，出乱码假字。
2. 只出现一次。同一句字重复写会触发重影叠字。
3. 加禁改句收尾：`文字逐字精确显示，不错字，不造词，不加字幕条`。违反会怎样：模型自动加跑马灯字幕条与乱码水印。

---

## 九、首帧身份保留契约（I2VA / FL2VA 必守）

顺序固定：**先保留、后变化、再落点**。

1. **第一段写 Preserve 清单**：脸、发型、服装、版型、颜色、比例、关键细节（痣/纹身/眼镜）。
2. **再写唯一的可观察动作**：一个主动作，拆「起—中—止」。
3. **最后写落点构图**：动作结束时主体在画面什么位置、镜头停在什么景别。

```text
保留首帧中的全部身份特征：面部五官、黑色齐肩短发、米色高领毛衣的版型与颜色、身体比例。
唯一动作：她抬起右手，把耳侧的头发别到耳后，指尖停一拍，放下。
落点：动作结束时她回正面向镜头，肩部以上中近景，窗光从左侧打亮右颊。
```

**红牌规则：禁止重描服装**。首帧图里已经有的服装信息，散文再写一遍 = 两个信息源打架，像素级烧掉身份。
判定标准：这句话首帧图里能看见吗？能 → 写「保留」，不写「是什么」。

## 十、负面词转正三法（H3 没有 negative 字段）

| 方法 | 做法 | 例 |
|---|---|---|
| ① 反向改正向保留 | 把禁的事项翻成「保持什么」 | 不要换脸 → 面部特征全程保持一致 |
| ② 一句 Avoid 短列表收口 | 提示词末尾一句 `Avoid: A, B, C`，≤3 项 | `Avoid: flickering, warped background, extra text` |
| ③ 「不要什么」翻成「要什么」 | 直接写期望形态 | 不要模糊 → 焦点落在眼睛，边缘锐利 |

**对照表（左边禁写，右边照抄）**：

| 禁写（否定式） | 转正写法 |
|---|---|
| 不要模糊 | 焦点落在主体双眼，背景轻微散景，边缘锐利 |
| 不要变形 | 部件数量与比例保持不变，双手五指自然 |
| 不要换脸 | 面部特征从头到尾与首帧一致 |
| 不要抖动 | 镜头运动平滑匀速，背景纹理稳定 |
| 不要字幕 | 画面无叠加文字，文字逐字精确且只出现一次 |
| 不要配乐盖台词 | 台词清晰位于声音最前景，现场声垫底 |
| 不要硬切 | 动作连续过渡，末帧由运动自然抵达 |
| 不要塑料感 | 皮肤保留毛孔细纹理，柔和高光滚降 |

**铁律**：Avoid 列表全片最多一句、最多 3 项。违反会怎样：否定词堆叠反而把被禁概念注入画面。

## 十一、时长—事件密度表

| 时长 | beat 数 | 运镜线索 | 台词量 | 装得下的内容 |
|---|---|---|---|---|
| 4–6s | 2 | 1–2 | ≤1 短句（≤8 字） | 单动作起止：转身/回头/推门 |
| 6–8s | 2–3 | 2 | 1–2 短句 | 单动作 + 一个反应拍 |
| 8–10s | 3 | 2–3 | 2 句对话 | 动作 + 对视 + 一句交锋 |
| 10–15s | 3–4 | 3 | 2–3 句（每句 ≤2 秒口型） | 完整微场景：进门→扫视→对话→反应 |

**判定标准**：一拍装不下就砍事件，不砍 beat。违反会怎样：一格里塞三个动作，全体变糊。

## 十二、与 Seedance 2.0 迁移矩阵

语义层（画面描述、七层拼装、三条翻译法则、物理一致性条款）**两平台完全共用**，只换语法壳：

| 语义概念 | Seedance 2.0 写法 | H3 写法 |
|---|---|---|
| 引用图片素材 | `@图片1`–`@图片9` | 参考模式槽位（subject_definitions 里逐个定义） |
| 引用视频素材 | `@视频1`–`@视频3` | 槽位 + 注明只复刻运镜/节奏/特效 |
| 首帧 / 末帧 | `start from this first-frame image` / `end on this last-frame image` | I2VA / FL2VA 模式选择 + 保留契约 |
| 负面词 | 独立负面段（分域拼装） | 无 negative 字段 → 三法转正（第十节） |
| 音效 | 时间线内写「音效：」 | `overall_soundscape` 字段 |
| 配乐 | 时间线内写「配乐：」 | `non_diegetic_music` 字段（不需要写 N/A） |
| 台词 | 引号 + 标注角色与情绪，单独成段 | 引号 + 说话人写在画面行内，按 beat 给足秒数 |
| 时长上限 | 单次 ≤15s | 单次 4–15s，默认 6s（必须显式写） |
| 语言 | 全中文（含图片提示词） | 中英皆可；运镜括号用英文，正文中文优先 |
| 优化器 | 无此参数 | `prompt_optimizer` 默认开，精控设 `false` |

**同一创意双平台各写一版（同一 8 秒镜头：雨夜巷口收伞回眸 + 推进）**：

Seedance 版：

```text
时长8秒，雨夜巷口，青橙电影调色，24fps。
0-4s：米色风衣女子在霓虹巷口收伞甩水，镜头缓缓推进，伞尖水珠落地溅开；音效：持续雨声、布料摩擦、水珠落地。
4-8s：推进继续，她缓慢回眸看向镜头，霓虹在右颊打出橙色轮廓光；音效：呼吸声渐重。
光影：右侧霓虹主光 + 左侧湿墙反光。负面：morphing face, flickering, warped background。
```

H3 版：

```text
[参数] 时长 8 秒 / 2K / 24fps / prompt_optimizer=false（在面板或 API 设，不进提示词正文）
integrated_multimodal_description:
[Shot 1] At 00:00.000，雨夜霓虹巷口，米色风衣女子收伞甩水，[Push in]，伞尖水珠落地溅开，湿沥青拖出竖向光轨。
At 00:04.000，[Push in] 继续，她缓慢回眸看向镜头，霓虹在右颊打出橙色轮廓光，画面止于肩部以上中近景。
overall_soundscape: 持续雨声，伞面收拢的布料摩擦声，水珠落地，她的呼吸声随回眸渐重。
non_diegetic_music: N/A
Avoid: flickering, warped background, extra text
```

## 十三、失败清单（症状 → 病因 → 修法）

| # | 症状 | 病因 | 修法 |
|---|---|---|---|
| 1 | 画面像会动的照片 | 没有时间 beat 或没有可见变化量，动作被均摊 | 补 2–3 个 beat，每拍写动作相位 |
| 2 | 末帧变成硬切 | 只写了终点状态没写路径（FL2VA 典型） | 补「起—中—止」路径段，写清怎么走到末帧 |
| 3 | 产品几何融化 | 同一方括号塞满指令 + 无保留声明 | 运镜砍到 2 个线索，retention 写明「几何轮廓与部件数量不变」 |
| 4 | 一格里塞了三个动作变糊 | 单 beat 超载 | 按 density 表拆事件，一拍一动作 |
| 5 | 镜头发抖、背景扭动 | 方括号堆叠超 3 条 | 全镜留 2–3 个运动线索，多余改散文 |
| 6 | 身份漂移换脸 | I2VA 重描服装与首帧打架 | 删掉服装重描，改写 Preserve 清单 |
| 7 | 字幕条凭空出现 | 写了 "no music"/否定式，或没加禁改句 | 删否定式，加「文字逐字精确，不加字幕条」 |
| 8 | 配乐盖住台词 | 台词没给足秒数 + 未声明声音层级 | 台词按 beat 分配秒数，写「台词位于声音最前景」 |
| 9 | 台词被拦腰切断 | 一句台词超过所在切片时长 | 长句拆成两句分拍，每句 ≤2 秒口型 |
| 10 | 参考素材猜错身份 | Ref2VA 没在 subject_definitions 定槽位 | 逐个素材写「图 N 是谁、视频 N 复刻什么」 |
| 11 | 音频整个静默 | 提示词含 "no music" 类否定式 | 改正向现场声或写 `non_diegetic_music: N/A` |
| 12 | 生成结果与提示词结构对不上 | 忘设 `prompt_optimizer: false` | 精控任务一律关优化器 |

# 14 · atlas 图集层（可填模板词库）

> 文件：`master/prompt-atlas.json`（370KB，源自主文档的机器可读投影）。
> 检索脚本：`scripts/atlas-lookup.ps1`。atlas 不替代主文档，它是主文档的**可填槽位视图**。

## 一、atlas 是什么，与主文档怎么分工

| | 主文档（26 卷 MD） | atlas（prompt-atlas.json） |
|---|---|---|
| 本质 | 成段原句 + 讲解 + 表格 | 树形槽位模板：节点 → 值 + 枚举选项 |
| 权威性 | **原句权威语料**，语义解释、句型、配方在这里 | 选项是**候选词清单**，不是成品句 |
| 强项 | 理解"为什么这么写"、取可抄范例 | 快速枚举"有哪些词可选"、中英对照、全库模糊搜 |
| 什么时候用 | 要原句、要句型、要配方、要解释 | 知道要哪一类词，但记不清库里有哪些；或想扫一遍全部候选 |

一句话：**主文档给人读，atlas 给模型扫。** 拿不准词义、需要上下文解释时，按 atlas 的 `_ref` 卷号回主文档原文。

## 二、节点字段协议

atlas 的 `提示词` 下是一棵树；凡含 `值` 字段的节点就是一个**可填叶子**（全库 279 个，7400+ 枚举选项）。

| 字段 | 含义 | 怎么用 |
|---|---|---|
| `值` | 当前槽位的填写值（通常为空） | 填写槽位就是给这里赋值；填的内容应从 `_opt` 里选或按 `_hint` 生成 |
| `_opt` | 枚举候选词数组，多为中英并列（`环绕orbit`、`f/1.4 浅景深 奶油焦外`） | 选词来源；只取**一个**（一处一源），不要并列同义词 |
| `_en` | 该槽位的英文总称 | 出英文提示词时做字段名参考 |
| `_hint` | 写法提示（如"运镜一次只写一个主运动 + 一个修饰速度"） | 优先级最高的填写约束，遵守它 |
| `_ref` | 指回主文档分卷（`卷1`、`主MD卷13`、`卷8摄影`） | 要原句、要解释、要更多选项时，用它去 `lookup-master.ps1` 翻主文档 |

## 四、三种用法

### 1. 取词（最常用）
```powershell
.\scripts\atlas-lookup.ps1 -Outline                      # 先看有哪些分卷
.\scripts\atlas-lookup.ps1 -Outline -Path "摄影层"       # 再看分卷下的小节
.\scripts\atlas-lookup.ps1 -Query "推轨,dolly,环绕"      # 跨全库搜，中英都写命中率翻倍
.\scripts\atlas-lookup.ps1 -Query "手持" -Path "运动与时间_视频"   # 限定子树搜
```
搜到后直接抄选项进提示词；`_ref` 带卷号，要原句就回主文档。

### 2. 填模板
把 atlas 当一张表单：按分卷顺序（①风格母语 → 时间光线 → 主体 → 场景美术 → 摄影层 → 灯光层 → 调色层 → 画幅）逐槽位给 `值` 赋值，每槽从 `_opt` 选一个。视频任务补填 `运动与时间_视频`，最后统一填 `负面词`。填完的槽位值集合 = 半成品，还需第 3 步。

### 3. 编译成提示词
**atlas 的树序 ≠ 提示词的语序。** 槽位填完后，必须按 SKILL.md 的 L1–L7 重排：
`L1 风格母语 → L2 题材套路 → L3 时间光线 → L4 主体 → L5 场景美术 → L6 摄影灯光 → L7 调色片质 → 画幅 → 视频段（运动与时间）→ 音轨（声音与音景）→ 负面块`。
槽位值只提供"词"，成句的连接、顺序、详略由七层拼装决定。

## 十、纪律

**atlas 里的选项是候选词，不是成品句。** 直接堆砌枚举词会得到清单感、无镜头感的提示词。成品句仍必须过 SKILL.md 的三条翻译法则：载体化、光学化、介质化；同一概念只取一个选项（一处一源），选完即弃、不回写 atlas。

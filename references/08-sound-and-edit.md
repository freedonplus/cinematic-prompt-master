# 08 · 声音音景 / 剪辑 / 转场

> **本册用途**：有声视频（Seedance 2.0 支持对白与音效）与成片剪辑。
> 心法：声音有四轨——**① 底噪 ambience（世界的呼吸）② 配乐 score（观众怎么感受）③ 点 SFX（关键一刻的落针）④ 断与留（切静/留声，把高潮顶上去）**。四步齐，音景自成。

## 二、城市与室内

`traffic hum with an occasional horn` / `the mechanical whine of an arriving subway` / `an overhead wall of indistinct voices` / `the industrial hum of transformers` / `a construction drill pulsing` / `a station announcement echoing flatly` / `a kettle whistling to a boil` / `a faucet dripping into the basin` / `a door latch clicking` / `footsteps on wooden stairs`.

**科幻机械**：`a servo whirring up` / `hydraulic hiss` / `a low reactor thrum` / `a holographic interface chirping` / `a synthetic voice with no breath`.

## 三、动作与悬疑 SFX

`the cold shing of a blade clearing its scabbard` / `steel on steel, one hard ring then grind` / `a fist thudding into ribs, the air leaving the body` / `boots scuffing gravel` / `a wet gasp` / `a heartbeat rising under the silence` / `fabric snapping taut` / `a chair leg scraping the floor`.

## 五、安静怎么写（给"静"一个机制）

| 类型 | 实现 |
|---|---|
| 绝对静 | `a dead silence so total the air seems to hold its breath` |
| 隔音感 | `muffled silence like being sealed behind soundproof walls` |
| 只余呼吸 | `so quiet that only shallow breathing fills the frame` |
| 真空静 | `a weightless vacuum-hush where no sound travels` |
| 耳鸣 | `a thin ringing in the ears cutting out all other sound` |
| 骤静 | `sudden deafening silence as the music stops mid-note` |
| 屏息 | `a held silence, everyone frozen, daring not to breathe` |
| 可闻落针 | `so still that a falling pin would echo` |
| 看得见的静 | `visible stillness — dust hanging, candle flame erect, not a ripple` |

**悬念静音公式**：高潮前切静 → 只留一个"最该被放大"的声（心跳/落针/吸气）→ 观众屏息被接管。写法：`music drops out, only the character's heartbeat left over the black frame`。

## 六、配乐情绪（给"从…到…"的走向，别只报曲风）

| 走向 | 写法 |
|---|---|
| 惆怅→惊惧 | `a lonely solo guzheng note, ominous low-frequency undertow building under it` |
| 平静→爆发 | `sparse piano swelling into a full orchestral hit` |
| 怀旧→失落 | `warm vinyl-flavored strings fading into a single sustained tone` |
| 压迫 | `a low sub-bass drone with no melody, ticking pulse` |
| 圣洁 | `choral hum, reverb-heavy, almost no rhythm` |

## 七、完整有声提示词模板（四轨一次写齐）

```
[画面镜头]，[环境音景 2–3 个底噪]，[配乐：曲风 + 从…到…的走向]，[偶发 SFX：在哪一刻触发 + 对情绪做什么]，[混音：ambience -18dB / score -12dB / SFX 峰值 -6dB]，[结尾切静或留声]
```

**成品（江南雨后空巷）**：
> `凌晨雨停的江南旧巷，空镜——石板路积水倒映昏黄路灯，瓦檐最后一滴雨坠落、在水面绽开涟漪（音效：单声水珠入水，清脆）。环境音景：远处闷雷滚过、屋檐零星滴水、雨后街道的空旷回声。配乐：孤独古筝单音与幽远箫声交替，内敛惆怅，随镜头推近门扉渐加一丝不祥低频暗流。门轴发出一声悠长吱呀自行开启——配乐骤停，只剩心跳鼓点在静默里擂响，画面定格门内漆黑。收束以低沉二胡长音。混音：环境 -18dB，配乐 -12dB，SFX 峰值 -6dB。`

# 下半｜剪辑与转场

## 八、转场五大抓手（先定位再选词）

| 抓手 | 含义 |
|---|---|
| 动作 Action | 借动作点/方向衔接（cut on action 最"隐形"） |
| 物体 Object | 借穿过画面的物体/相似形状衔接 |
| 光 Light | 白闪/黑场/眩光/漏光过渡 |
| 音 Sound | 声音先入、卡拍、声音桥 |
| 图形/字 Graphic | 构图相似、划像、文字图形 |

## 九、常用转场速查

| 类型 | 写法 |
|---|---|
| 硬切 | `hard cut`、`straight cut` |
| 叠化 | `soft dissolve between shots` |
| 淡入淡出 | `fade in from black`、`fade out to black` |
| 甩接 | `cut on a whip pan, motion-blur cut` |
| 匹配剪辑 | `match cut connecting the two similar shapes` |
| 跳切 | `jump cut to skip time` |
| 动作顺接 | `cut on action, seamless continuation of movement` |
| 遮挡转场 | `[object] passes in front of the lens, then it opens onto [new place]` |
| 焦点转场 | `a slow rack focus blurs the frame, and when it refocuses we are in [new scene]` |
| 光晕过渡 | `a strong backlight flares the lens to white, dissolving into [next moment]` |
| 声音先行 | `J-cut with audio leading into the next shot` |
| 声音延续 | `L-cut where sound carries over` |
| 蒙太奇 | `fast montage sequence` |

## 十、AI 单镜内可生成的转场（写进一句话）

- `camera whips past and settles on [new scene], a whip-pan transition`
- `[object] passes in front of the lens, then opens onto [new place]`
- `a slow rack focus blurs the frame, refocusing in [new scene]`
- `a backlight flares to white, dissolving into [next moment]`
- `he steps through the doorway and emerges in [new setting], a match transition`

## 十一、多镜成片的拼接顺序

1. 逐镜生成（题材库 + 角色锁 + 摄影层）。
2. 同空间换机位 → 硬切/动作点；异空间 → 遮挡或叠化承接。
3. 想让"球变圆月"这类匹配转场成立：**上镜结尾与下镜开头写同一形状关键词**，再叠化。
4. 结尾统一淡出/闪黑。

**分镜转场表头**：`镜号 | 景别 | 画面 | 运镜 | 转场到 | 转场方式 | 声音`

## 十二、转场/剪辑负面

`no abrupt random transitions, no awkward jump, no camera stutter, no instant scene pop, smooth continuous camera, no crossfade ghosting, no jumps in screen direction, no mismatched eyeline`

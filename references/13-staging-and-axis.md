# 13 · 站位与轴线（Staging & Axis）

> 来源：`storyboard-sheet` 的衔接体系（空间蓝图 / 轴线 / 机位表 / screen_side / ref_binding / 首尾态接力 / 比例锚 / 穿模分离 / 切点类型），重写为**提示词语言**。本技能出的是提示词，不是故事板——所以这里的"一格"就是**一条提示词**；站位不靠脚本校验，靠**在提示词里把字写死**。
>
> 两条使用分界：
> - 多镜任务（分镜、短剧、系列延展）：先填第 11 节「站位卡」，再把卡里的句子逐条分进 L4/L5/L6，逐镜原句复用。
> - 单图单镜：只走第 12 节「三句式站位」，不写整套卡。
>
> 归层口诀：**实位与比例锚进 L5，侧位与机位进 L6，朝向与动作相位进 L4。**

---

## 1. 站位漂移的三个独立变量

只锁一个必漂。三个变量互不推导、互不替代，每条提示词里各锁各的。

| 变量 | 回答什么 | 写进哪层 | 只锁它会怎样 |
|---|---|---|---|
| 空间实位 | 人在场景里的坐标（距哪个固定物多远） | L5 场景 | 机位一变或模型重排构图，人在画面里就翻边 |
| 屏幕侧位 | 本机位下谁在画面哪一边 | L6 摄影 | 相邻两镜一格在左一格在右，观众判定换人了 |
| 机位 | 镜头在哪、多高、朝哪、什么景别 | L6 摄影 | 机位自由漂移，轴线被无声破坏，左右关系随机翻转 |

一句话压住三者：**L5 写死人在空间的哪里，L6 写死镜头在哪 + 谁在画面哪边，三层缺一必漂。**

---

## 2. 空间蓝图：用场景固定物做坐标

规则：每个角色的位置 = **距哪个固定物多远 + 在固定物哪一侧（用固定物描述）+ 身体朝向谁**。固定物必须是画面里看得见的实体：停止线、第 N 条白条、缘石、门框、桌沿、护栏立柱、台阶第几级。
**禁止**用「前景 / 后景 / 画面左侧」描述角色位置——这些随景别和机位变化，是站位漂移的头号原因。违反会怎样：换个景别，模型把"前景"重新解释一次，人就从斑马线跳到马路上。

验收法：把蓝图里所有「左/右/前/后」删掉，位置仍能唯一确定；删不干净就重写。

三个场景的蓝图范例（可直接粘进提示词的 L5）：

```text
【街口】空间蓝图：小狗坐在白色停止线与斑马线第一条白条之间的沥青上，臀部离停止线约 45 厘米、
离白条约 30 厘米，身体正对信号灯杆；小猫坐在小狗靠缘石一侧约 25 厘米处、离停止线再远约 15 厘米，
尾巴绕在前爪上；两者都在停止线之后、白条之前，不踩白条。
```

```text
【室内餐桌】空间蓝图：长方形木餐桌，桌高约 75 厘米；女人坐在靠窗长边的中段，椅背距桌沿约 30 厘米，
身体正对桌面中央的青瓷茶壶；男人坐在她对面短边一端，胸口距桌沿约 20 厘米，身体正对女人；
茶壶位于桌面几何中心，两只茶杯分列茶壶两侧各约 15 厘米，分别靠近两人各自的桌沿。
```

```text
【武侠庭院】空间蓝图：青石板庭院，北面为月洞门，门洞高约 2 米；剑客站在月洞门内一步、
距门槛约 80 厘米，剑尖斜指地面；对手站在庭院中央石桌南侧、距石桌东缘约 1.5 米，刀背贴右肩；
石桌位于庭院正中，两只石鼓凳分列石桌两侧。
```

违反会怎样：蓝图写成"一人站前景、一人站背景"，下一个镜头两人谁前谁后随机；写成"左边的男人"，机位一动他就到了右边。

## 3. 轴线定则

1. **取轴**：取两个主要角色（或角色与主要目标，如信号灯、门洞）的连线为 180° 轴。轴本身写在站位卡里，不写进每条提示词；提示词里落的是它的两个推论——机位方位与左右定则。
2. **同侧**：全组机位只能在这条轴的一侧。违反会怎样：同一人被认成两个人，方向感全丢。
3. **左右定则句**（每条提示词 L6 原句复用）：`在道路侧机位看，狗在画面左侧、猫在画面右侧；老人始终从猫那一侧（缘石缺口）进入。`违反会怎样：只锁机位不写这句，模型自行重排构图，左右翻转。
4. **越轴**：确需越轴（反打、过肩），必须显式声明并给过渡——越轴镜的提示词里写：`反打镜头（越轴）：接住狗抬头看向猫的视线对齐；下一镜切回原侧位。`一组反打只能成对出现，连续两镜都越轴、或越轴无过渡，观众必迷失。
5. **相邻机位水平夹角 ≤ 90°**。违反会怎样：两镜接近正反方向，等于无声越轴，画面左右关系突变。

## 4. 机位表：C1–Cn

每镜一个机位编号，五项写死：位置 / 高度 / 朝向 / 景别 / 运动。机位表住在站位卡里；每条提示词的 L6 从表中抄对应一行，原句复用。

三人对话场机位表实例（轴线 = 甲—乙连线，丙在乙侧后方）：

```text
C1：甲侧后方 2 m，离地 150 cm，水平朝乙丙，全景，固定机位。
C2：乙侧后方 1.5 m，离地 150 cm，水平朝甲丙，中景，慢推 20 cm。
C3：过肩（甲肩后 60 cm），离地 155 cm，朝乙，近景，固定机位。〔越轴镜头〕
C3b：视线对齐过渡：乙正面平视，离地 155 cm，特写，固定机位。
C4：丙正面，离地 150 cm，朝甲乙方向，中近景，右摇 10°。
```

小步移动三限（相邻两镜之间）：

| 限 | 阈值 | 违反会怎样 |
|---|---|---|
| 高度差 | ≤ 一个身位（约 170 cm） | 视线方向突变，观众判定换空间 |
| 景别差 | 不连跳两级 | 全景直跳特写，环境信息断档，观众迷失 |
| 水平夹角 | ≤ 90° | 无声越轴，左右翻转 |

景别台阶表（相邻差 ≥3 即连跳两级，必须补一格过渡景别）：

```text
1 大远景 / 2 远景 / 3 全景 / 4 中景 / 5 中近景 / 6 近景 / 7 特写 / 8 大特写
例：3 全景 → 6 近景 = 跳三级，禁止；中间补 4 中景或 5 中近景。
```

## 5. 屏幕侧位：screen_side

机位表只说明"镜头在哪"，不说明"谁在画面哪边"；两者互不推导，必须单独再锁一遍。

- 取值只有 `left` / `center` / `right`，只列本镜真正可见的角色。
- 短语生成规则：`left` → `X在画面左侧`；`right` → `X在画面右侧`；`center` → `X在画面中部`。**逐字复用，禁止改写**为"左边 / 偏左 / 左半边 / 靠左"。违反会怎样：同义变体让模型每次重新猜侧位，短语失去锁定作用。
- 每条提示词的 L6 必须原句包含侧位短语；写了 screen_side 但提示词里没有对应短语，等于没锁。
- 反打必须成对：反打镜提示词写 `反打镜头（越轴）：…`，下一镜提示词必须切回原侧位短语。连续两镜反打，观众方向感崩。
- 单角色独占画面时不写暧昧方位，直接给 `center` 或按构图写死一侧；下一镜换景别仍沿用同一侧。

## 6. 首尾态接力：in_state / out_state

硬规则：**第 N 镜的出格状态与第 N+1 镜的入格状态逐字相同**——不是"基本一致"，是一个字都不改。违反会怎样：上一镜结束人还坐着，下一镜开头已站起来，中间动作凭空丢失。

五项必落字（每条状态句里五项都要能找到对应文字）：

| 项 | 落字要求 | 违反会怎样 |
|---|---|---|
| 位置 | 距固定物的距离原样复用 | 换镜即瞬移 |
| 朝向 | 身体/头/视线正对谁 | 视线目标跳变 |
| 动作相位 | 起势 / 发力顶点 / 接触 / 收势 / 余势 / 定格 | 相位断档，卡顿感 |
| 接触点 | 接触在谁身上哪个部位；无接触写"无接触" | 拳已出手下一镜却收回来 |
| 表情强度 | 强度写死（怒目而视 / 微蹙眉） | 情绪跳变 |

三镜接力实例（每段直接进提示词 L4，入格状态句放在动作句之前）：

```text
镜1 出格状态：狗坐姿不动、视线上仰对准红灯，尾巴绕在前爪上，臀部仍在停止线后原位，双耳竖立绷紧。
镜2 入格状态：狗坐姿不动、视线上仰对准红灯，尾巴绕在前爪上，臀部仍在停止线后原位，双耳竖立绷紧。
镜2 出格状态：狗前腿撑地起身、身体离地约 15 厘米（起身相位），头转向缘石缺口，双耳保持竖立。
镜3 入格状态：狗前腿撑地起身、身体离地约 15 厘米（起身相位），头转向缘石缺口，双耳保持竖立。
镜3 出格状态：狗四肢着地站立于白条之前，头正对缘石缺口，尾巴下垂，双耳放松。
```

## 7. 参考图链与槽位绑定（ref_binding）

一槽一主体。一次传多张参考图时，模型不知道哪张对应哪个主体，会把身份、朝向、服装串位——这是"两个主体的参考搞反"的直接原因。

三类角色分开：

| role | 提供什么 | 绑什么素材 |
|---|---|---|
| identity | 身份：长相、毛色/脸型、体型、标志物 | 角色定妆图（空背景三视图优先） |
| layout | 空间：布局、地面关系、光线方向、比例 | 上一镜成品整幅 |
| style | 风格：画风、介质、颗粒 | 风格样张 |

硬规则：双主体不许共用一张图；identity 与 layout 必须分槽；换场参考图链断开、以新首镜重开，不许默默断链。违反会怎样：把上一镜整幅图当身份图，下一镜角色的脸就长成上一镜的构图。

ref_binding JSON 片段与对应提示词原句：

```text
ref_binding:
[
  { "slot": "图片1", "subject": "小狗", "role": "identity" },
  { "slot": "图片2", "subject": "小猫", "role": "identity" },
  { "slot": "图片3", "subject": "镜3", "role": "layout" }
]
```

```text
提示词原句（逐槽写，中文）：
图片1 仅提供小狗的毛色、脸型、体型与绿色项圈，不提供背景与构图。
图片2 仅提供小猫的虎斑纹、耳形与体型，不提供背景与构图。
图片3 仅提供上一镜的空间布局、地面关系与光线方向，不照抄构图。

英文（H3 / Veo / Sora）：
Image 1 provides only the puppy's coat color, face shape, body proportions and green collar; no background or composition.
Image 2 provides only the kitten's tabby pattern, ear shape and body proportions; no background or composition.
Image 3 provides only the spatial layout, ground contact and light direction from the previous shot; do not copy its composition.
```

槽位编号必须与工具实际收到的素材顺序一致：`图片1` = 第一张（Seedance）；H3 用 `Image 1`；Veo/Sora 在素材清单里按同名编号声明。

## 8. 比例锚

规则：每场选**一个**场景固定尺寸物写进每条提示词（进 L5），角色尺寸用锚换算（进 L4）。一场只选一个锚，换场才换。违反会怎样：不给锚，景别一变角色就忽大忽小。

常用锚与换算表：

```text
斑马线白条宽约 45 厘米 ｜ 缘石高约 15 厘米 ｜ 门洞高约 2 米 ｜ 餐桌高约 75 厘米
护栏立柱间距约 1.2 米  ｜ 台阶一级高约 15 厘米 ｜ 石鼓凳高约 40 厘米
```

| 对象 | 换算句写法示范 |
|---|---|
| 小狗 | `狗高约 20 厘米，约白条宽的一半` |
| 站姿成人 | `男人身高约为门洞高（2 米）的五分之四` |
| 坐姿成人 | `女人坐姿头顶低于桌面约 40 厘米，桌面高约 75 厘米` |
| 石桌 | `石桌面高约石鼓凳高的一倍半` |

锚句与换算句每镜原句复用；特写时可只保留锚句、省换算句，不可两者全删。违反会怎样：近景删锚后模型自行脑补尺寸，切回全景比例全错。

## 9. 双主体分离与穿模

穿模几乎都是"两个主体的轮廓没有被要求分开"造成的，重出治不了，必须正向分离句 + 负向四段同时上。

正向分离四件（每条提示词都要有，落 L4/L5）：
1. **间隙句**：两主体之间保留可见间隙（如"两者之间至少留出半个身位"）。
2. **前后层次句**：写死谁在前、谁被谁部分遮挡（特写也要写）。
3. **接触阴影句**：各自独立的接触阴影落在地面同一侧，不共用一团阴影。
4. **地面关系句**：足部/臀部落在同一地平面，不悬空、不埋入地面。
复杂动作（抱、压、摔、抢夺）必须写**接触点**：接触在谁身上哪个部位、哪部分被压住。只写"压住"不写接触点，必穿模。

负向四段（逐段点名，不写笼统的"不要穿模"）：

```text
base：不出现文字、字幕、水印、编号、边框
anatomy：肢体互相穿插、多余手臂手指、身体融合粘连
geometry：道具或背景物体穿过身体、衣物穿过身体、角色悬浮于地面
separation：两主体轮廓粘连、共用一团阴影、前后遮挡关系不明
```

六组「错→对」对照句：

```text
1 错：小猫依偎着小狗。
  对：小猫坐在小狗靠缘石一侧，两者肩部之间留出约半个身位，各自有独立的接触阴影落在沥青上。

2 错：两人拥抱在一起。
  对：男人双臂环住女人肩背，双手交叠于她左肩胛外侧，两人胸口相贴、面部分开约 10 厘米，双足落在同一块地砖上。

3 错：反派一拳打在主角身上。
  对：反派左拳拳面接触主角左小臂中段外侧，主角小臂横于胸前格挡，反派拳头被小臂挡住未触及躯干。

4 错：一人在前一人在后。
  对：小猫在小狗前方约一步、靠近画面下缘一侧，小狗部分躯干被小猫身体遮挡，两者的影子投向画面同侧地面。

5 错：狗从车前跑过。
  对：狗沿白条内侧奔跑，身体与车身之间保持约一个身位间隙，四肢都接触沥青地面，不悬空。

6 错：两人对峙，剑拔弩张。
  对：剑客与对手相距约两步（约 1.5 米），剑尖斜指对方脚前约 30 厘米处，刀背贴对手右肩，两人影子投向同一方向，双脚踩在同一块青石板上。
```

违反会怎样：只给负面不给正向，模型不知道"分开多少、谁前谁后"，粘连随机复发；只给正向不给负面，畸形手指与悬浮照样出现。

## 10. 五种切点类型

每镜在提示词结尾用一句话写清"本镜接住什么"，禁止写"自然转场 / 流畅衔接"这类空词。落 L6（运镜/剪辑指令位）或视频提示词的衔接句位。

| 类型 | 该接住什么 | 提示词写法（一句） |
|---|---|---|
| 动作切 | 动作未完的那一帧 | `切点：接住左脚刚落地的那一帧，动作未完成即切。` |
| 同构图跳切 | 时间省略 | `切点：同机位同构图跳切，仅时间状态由红灯变为绿灯。` |
| 视线切 | 视线定住的人/物 | `切点：接住她视线定住的方向——信号灯杆，下一镜由此切入。` |
| 声音先行切 | 先出声后出画 | `切点：脚步声先入 1 秒，画面后到，声音来自缘石缺口方向。` |
| 硬切 | 已完成的动作 | `切点：硬切，接住上一镜已完成的起身动作。` |

违反会怎样：切点空缺，模型自行选择衔接帧，前后镜的动作相位对不上。

## 11.【核心交付物】站位卡填空模板

多镜任务开工第一件事：先填两张站位卡（中文版给 Seedance/即梦/用户；英文版给 H3/Veo/Sora）。填完后把卡里的句子逐条分进各镜提示词：实位句与比例锚进 L5，朝向/动作句进 L4，机位/侧位/光位句进 L6。逐镜原句复用，禁止改写。

中文站位卡（纯文本，直接复制填写）：

```text
【站位卡｜场景名：____】
场景原点：（选一个看得见的固定物：停止线与第一条白条的交点 / 桌面几何中心 / 月洞门门槛）
固定物清单：____、____、____（各带一句形态：材质/颜色/数量，全组不改）
空间蓝图：（按第 2 节写法，每角色一句：距哪个固定物多远 + 哪侧 + 朝向谁）
角色A（____）：
  坐标：距（固定物）约____厘米，在固定物（用固定物描述的一侧）
  朝向：身体正对（固定物/角色）
  屏幕侧位：画面左侧 / 画面中部 / 画面右侧（取一）
  尺寸：____（用比例锚换算）
角色B（____）：（同上四项）
轴线与左右定则：轴线为（角色A）—（角色B）连线；在（道路侧/南侧）机位看，（角色A）在画面左侧、
  （角色B）在画面右侧；（第三方/新角色）始终从（角色B）那一侧进入。
机位表：
  C1：（位置）（高度）（朝向）（景别）（运动）
  C2：…
  C3：…〔越轴镜头时注明，并给过渡镜编号〕
比例锚：（场景固定尺寸物一句，如：白条宽约 45 厘米）
光位：主光从（方向）来，（光质/光比/色温一句，全组不改）
状态卡：（可变对象各一句固定状态：灯态/时间/天气/门，全组不改）
出格状态（首镜基准）：（位置/朝向/动作相位/接触点/表情强度五项落字）
```

英文站位卡（给 MiniMax H3，同字段）：

```text
[STAGING CARD | Scene: ____]
Origin: (one visible fixed object, e.g. intersection of stop line and first stripe / table center / moon-gate threshold)
Fixed objects: ____, ____, ____ (one form line each: material / color / count, never changed across shots)
Spatial blueprint: (one sentence per character: distance from which fixed object + which side + facing whom)
Character A (____):
  Position: about ____ cm from (fixed object), on the side described by that object
  Facing: body toward (object/character)
  Screen side: left / center / right (pick one)
  Scale: ____ (converted via the proportion anchor)
Character B (____): (same four fields)
Axis & left-right rule: axis = (A)-(B) line; from the (road-side) camera, (A) appears on the left side of the frame,
  (B) on the right; (third party) always enters from (B)'s side.
Camera list:
  C1: (position) (height) (aim) (shot size) (movement)
  C2: ...   C3: ... [mark cross-axis shots and give the transition shot id]
Proportion anchor: (one fixed-size object, e.g. the crosswalk stripe is about 45 cm wide)
Light: key light from (direction), (quality / ratio / color temperature, one line, never changed)
State card: (one fixed line per variable object: traffic light / time / weather / door)
Out-state (baseline): (position / facing / action phase / contact point / expression intensity, all five in words)
```

使用规矩：卡里每一句生成后逐镜原句粘贴，改一个字就失去锁定作用；换场重开一张卡并断参考图链。

## 12. 轻量版：三句式站位

单张图、单个镜头，不值得写整套卡时，用三句式：**一句空间锚 + 一句屏幕侧位 + 一句比例锚**。三句缺一，退回整套卡。三个场景范例（可直接粘）：

```text
【街口独镜】小狗坐在白色停止线与斑马线第一条白条之间的沥青上，身体正对信号灯杆；
小狗在画面中部偏下、老人从画面右侧缘石缺口进入；白条宽约 45 厘米，狗高约 20 厘米，约白条宽的一半。
```

```text
【室内独镜】女人坐在木餐桌靠窗长边中段，身体正对桌面中央的青瓷茶壶；
女人在画面左侧、男人在画面右侧，两人之间隔桌面中央的茶壶；桌高约 75 厘米，
女人坐姿头顶低于桌面约 40 厘米。
```

```text
【庭院独镜】剑客站在月洞门内一步、距门槛约 80 厘米，剑尖斜指地面，对手站在中央石桌南侧；
剑客在画面右侧、对手在画面左侧，石桌位于两人之间的画面中部；门洞高约 2 米，
对手身高约为门洞高的五分之四。
```

违反会怎样：三句式漏掉比例锚，单图不出错、一旦延展成系列图第一张就漂。

## 13. 站位自检清单

| 机器可查（写完逐条 grep 提示词原文） | 人眼可查（出图后逐镜过目） |
|---|---|
| 每条提示词含完整空间蓝图句，且蓝图句全组逐字相同 | 角色左右位置全组一致，无一镜翻边 |
| 蓝图句删掉所有"左/右/前/后"后位置仍唯一 | 反打成对出现、下一镜已切回原侧位 |
| 每条提示词含侧位短语，措辞与 screen_side 生成式逐字一致 | 两主体之间有可见间隙，无粘连、融合、穿插 |
| 状态句（in/out）相邻逐字相同 | 相邻机位夹角目测 ≤ 90°，高度差未超一个身位 |
| 景别编号相邻差 <3，无连跳两级 | 同一场景固定物在各镜中形态、颜色、数量一致 |
| 机位行五项齐全（位置/高度/朝向/景别/运动） | 视线目标全组一致（看灯就都看灯） |
| ref_binding 一槽一主体，逐槽用途句在提示词原句出现 | 光位与影子方向一致，色温没有偷偷变暖 |
| 比例锚句在每条提示词出现 | 角色相对比例锚的尺寸无跳变 |
| 负向四段（base/anatomy/geometry/separation）齐全且原句出现 | 该出场的角色都真实入画，无人对着空气演 |
| 换场镜已断参考图链并以新首镜重开 | 状态卡对象（灯/门/天气）语义自洽，无红绿混搭 |
| 越轴镜有显式"反打（越轴）"字样与过渡镜编号 | 切点处前后两镜动作相位接得上 |
| 接触类动作句含接触点部位 | 特写中双主体都可用服装特征辨认 |

两栏各 12 条，两栏全过才交付；机器栏不过先改字，人眼栏不过改句子重出。

## 14. 常见站位崩坏 10 例

| # | 症状 | 责任句 | 修法 |
|---|---|---|---|
| 1 | 一格在左一格在右 | 缺侧位短语，或侧位短语被改成"左边/偏左" | L6 补 `X在画面左侧` 原句，全组统一措辞 |
| 2 | 两个人粘成一个 | 缺间隙句与前后层次句 | L4 补"两者之间至少留出半个身位 + 谁被谁部分遮挡"，负向补 separation 段 |
| 3 | 角色忽大忽小 | 缺比例锚句 | L5 补锚句 + L4 补换算句，逐镜原句复用 |
| 4 | 影子方向打架 | 光位句各镜不同或被删 | L6 统一一句光位句全组照抄，影子方向写入 L5 |
| 5 | 越轴后观众迷失 | 越轴镜无过渡镜、无视线对齐 | 越轴镜标"反打（越轴）"并接视线切过渡，下一镜切回原侧位 |
| 6 | 特写只剩一个人在演对手戏 | 特写句未点名第二主体 | L4 用服装特征与侧位短语把两个主体都写进画面（"画外一侧露出对手持刀的右肩"） |
| 7 | 两个主体的参考图搞反 | ref_binding 缺失或一槽绑两主体 | 一槽一主体重绑，逐槽写"图片N 仅提供…，不提供背景与构图" |
| 8 | 上一镜坐姿下一镜站着 | 出格状态与入格状态没有逐字接力 | 复制上一镜出格状态五项原句作本镜入格状态 |
| 9 | 角色悬空或埋进地面 | 缺地面关系句 | L5 补"四肢/臀部落在同一地平面，不悬空不埋入"，负向补 geometry 段 |
| 10 | 换镜后固定物变形（白条变宽、门变矮） | 固定物形态句各镜措辞不一 | 固定物清单一句形态全组照抄，换场才允许换 |

排查顺序：出问题的镜 → 找它参考的上一镜 → 对比两条提示词哪句被改了 → 只修那一句、只重出受影响镜及其下游。

## 三、表情：从"形容词"到"肌肉链"

**公式：情绪 = 眼周可见（眉+眼+口+脸肌）+ 躯干（头颈肩手）+ 生理反射（泪/汗/面色/呼吸）+ 可选声音**

- ✗ `sad, crying`
- ✓ `嘴角向下压、眉心微蹙、眼眶蓄水光却强忍不落、低头避开视线、喉结轻滚、呼吸发颤`

### 幅度分级（决定拍多近）
| 级 | 中文/英文 | 适用 | 例 |
|---|---|---|---|
| 0 | micro / imperceptible 微表情 | 特写 | 只有睫毛颤一下 |
| 1 | restrained 克制 | 近景 | 眉抬一线、嘴角微抽 |
| 2 | readable 明显 | 中近景 | 眼眶泛红、下唇抿紧 |
| 3 | dramatic 外放 | 中景 | 泪滑落、肩发抖 |
| 4 | exaggerated 夸张 | 动画/喜剧 | 五官挤成一团 |

**高反差三招（比单一情绪更出片）**：含泪带笑 `bittersweet, smiling with wet eyes`；强颜欢笑 `forced smile, eyes without light`；平静暗涌 `still body, trembling fingers, white knuckles`。

### 七情关键词（每样取 2–3 个部位即可）
| 情绪 | 可写部位链 |
|---|---|
| 喜 JOY | 眼角上提 + 苹果肌隆起 + 唇自然分开露齿 + 眉舒展 |
| 怒 ANGER | 眉压低内聚 + 鼻翼外扩 + 下颌前咬 + 太阳穴筋起 |
| 哀 SORROW | 眉内侧上扬 + 嘴角下压 + 泪光 + 视线失焦 |
| 惊 SURPRISE | 眉高扬 + 眼圆睁 + 唇微张 + 后仰半步 |
| 惧 FEAR | 瞳孔收缩 + 面色发白 + 唇颤 + 手指蜷紧 |
| 嫌 DISGUST | 上唇抬起 + 鼻翼皱 + 目光侧移 |
| 平 NEUTRAL | 面无表情 + 眼神定点 + 唇线平直（压迫感最强） |

### 眼神专项（最出戏的部位）
`direct eye contact, unblinking 直视` / `staring into the distance 出神` / `sizing up 打量` / `stealing a glance then averting 偷瞄后移开` / `lowered lids 垂眸` / `icy piercing 眼锋如刀` / `burning gaze 灼热` / `hollow unfocused 空洞失神` / `glassy moist 眼底水光` / `murderous squint 杀意微眯` / `heavy-lidded sluggish 疲惫` / `dazed hazy 醉态` / `eyes lighting up 眼睛一亮`

**眼神写作小公式**：视线方向/状态 + 附加情绪色 + 一个生理小动作。
> `他抬眼，目光极快地掠过她，在触到的前一瞬又移开，喉结轻轻滚动。`

## 四、人体质感（把"塑料皮肤"救回来）

**两层法：表面肌理 + 成像片质，缺一层就假。**

| 层 | 该写什么 | 可抄词 |
|---|---|---|
| 真实自然 | 毛孔、绒毛、细纹 | `visible pores at the nose wings, peach fuzz catching rim light, fine dermal lines, natural mottling` |
| 妆造系 | 底妆质地 | `velvet matte finish` / `creamy dewy skin` / `glass-skin luminous` / `subtle smoothing, pores retained` |
| 岁月与状态 | 纹与斑 | `crow's feet, nasolabial folds, neck lines, scattered freckles, sun spots, acne scars` |
| 情绪状态 | 病态/疲惫 | `pallid waxy complexion, flushed fever cheeks, dark under-eye circles, cracked dry lips` |

**发丝**：`individual strands catching the rim light, flyaways, wet-look clumped strands, split ends, grey at the temples`。
**唇与眼**：`lip texture with fine vertical lines, glossy wet sheen` / `moist glassy cornea, sharp catchlight, visible iris pattern`。

**必备正负对**：
- 正：`skin-like breathing texture, subtle dimples and bumps`
- 负：`plastic skin, waxy, poreless, airbrushed to death, over-smoothed`

## 五、一致性工程（跨镜不换脸的四件套）

| 手段 | 做法 | 适用 |
|---|---|---|
| 固定描述块 | 长相段+全身段原样复用，只换场景/动作 | 全部平台 |
| 基准三视图 | 先出一张空背景 turnaround，后续全部垫它 | 全部 |
| 固定 seed | 首张满意后锁 seed，微调描述不换脸 | MJ `--seed`、SD |
| 参考图/首帧 | 上一镜成图作为下一镜首帧或角色参考 | 即梦/可灵/视频 API |
| 局部重绘 | 脸对衣错→只 inpaint 服装区 | SD |

### 三视图可抄句式
- 最简三视图：`character reference sheet, front view / back view / side view of the same person, full body, neutral plain background`
- 带四分之三：`character turnaround, front, three-quarter and back views, consistent face and outfit, plain grey backdrop`
- 游戏设定表：`game character model sheet, full-body orthographic front and back views, matching features, pure white background`
- 服装表：`fashion design turnaround, same outfit front/back/side, full length, neutral background`

**角度词**：`front view, facing camera, eye-level` / `full left profile` / `three-quarter view 3/4 left` / `back view` / `high angle` / `low angle` / `top-down bird's-eye`。
**景别词**：`head-and-shoulders bust` / `medium waist-up` / `three-quarter knee-up` / `full-body` / `extreme close-up`。

### 多角色防串脸
A、B 各写一段**差异最大化**的长相段（一圆一长、一棕瞳一黑瞳、痣位不同），正向加 `two distinct people`，负向加 `same face on both, morphing faces, swapped features`。

### 一致性负向兜底（每次锁人任务都贴）
`different person, morphing face, inconsistent eyes, one eye bigger, duplicated features, face swap, same face on both characters, mismatched outfit between views, clothes changed between shots, hair changed between views, extra limbs, distorted proportions, cross-eyed, asymmetric eyes`

## 六、主体非人类：生物与物品

**真实生物要给"可写特征"**：`feather ruff texture`、`wet nose highlight`、`claw curvature`、`scale iridescence`、`pupil slit`。
**奇幻生物要拆件**：`head + horn structure + wing membrane + scale plating + tail tip`（一件一件写，别写"一条很酷的龙"）。
**物品三件套**：材质识别词（`brushed aluminium`、`borosilicate glass`）+ 表面状态（`hairline scratches`、`fingerprint smudges`）+ **"功能在动作中"**（`steam curling out of the spout`、`a drop suspended at the lip`）。

> 判断标准：写完这段，读者能不能在脑中"摸到"它？摸不到就是词不够具名。

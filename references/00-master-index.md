# 00 · 主文档总索引（权威语料的入口）

> 本技能的一切具名词以 `master/AI图像视频生成提示词_超细分主文档.md` 为**唯一权威**。
> `references/01–11` 只是**速查卡**（压缩、可随手抄）；`12–14` 是平台语法壳与站位工程；凡速查卡里没有、或拿不准的具名词，必须回主文档原文。

## 一、语料优先级协议（写提示词时按这个顺序取词）

| 级 | 来源 | 用途 | 冲突时 |
|---|---|---|---|
| **P0** | `master/` 主文档（26 卷） | 具名词、参数、范例、负面词 | **以它为准** |
| **P1** | `references/01–11` 速查卡 | 快速定位、表格化速查、常用组合 | 与 P0 冲突时听 P0 |
| **P1.5** | `master/prompt-atlas.json` + `references/14` | 可填槽位、枚举候选、中英对照 | 只给候选，句子仍回 P0 |
| **P2** | `references/12` H3 语法壳、`references/13` 站位轴线 | 平台结构、跨镜坐标 | 结构听它，词回 P0/P1 |
| **P3** | 自创词 | 允许，但必须具名、可被画面验证 | 自创词 ≤ 全篇 20% |

**三条硬规则**
1. **具名优先**：能查到专名（`Rembrandt loop`、`mamumian skirt`、`Rimowa` 级具体细节）就不写泛词。
2. **一处一源**：同一条提示词里，同一概念只用一种说法，不并列同义词（"朱红/vermilion/正红"选一个）。
3. **查不到就降级，不要编**：主文档没有的具名词，改写为"可验证的物理描述"，并在交付时标注"该词为自创"。

## 四、检索指令集（怎么在主文档里"精准取词"）

### 1. 自成体系的一步取词（脚本）
```powershell
# 按关键词查，返回命中标题 + 行号 + 上下文
.\scripts\lookup-master.ps1 -Query "Rembrandt,伦勃朗" -Context 2
# 只查某一卷（1–26）
.\scripts\lookup-master.ps1 -Query "bokeh" -Volume 8
# 查"某卷有哪些小节"
.\scripts\lookup-master.ps1 -Outline -Volume 20
```

### 2. Agent 内直接 Grep（等价做法）
| 目的 | pattern | 说明 |
|---|---|---|
| 找具名词 | `伦勃朗\|Rembrandt` | 中英都写，命中率翻倍 |
| 找某卷小节 | `^## .*织物` | `^#` 是卷，`^##` 是小节 |
| 找"可抄短语" | `可抄\|写法\|提示词写法` | 这些段落给的是成品短语 |
| 找中英对照范例 | `中：\|英：\|English:` | 卷2/3/4/13/16/18 有成品对照 |
| 找负面词 | `negative\|负面\|禁止` | 分域负面集中在卷9/17/19/20/21/22 |
| 找参数表 | `\| 参数 \|` 或 `f/\|K \|` | 卷8/18/23 表最多 |

### 3. 读取策略（别整篇读完，553KB 读不完）
1. 用 `-Outline` 或 `Select-String '^#{1,2} '` 拿目录树；
2. 按卷起点行号 + 下一卷起点行号，只读该区间；
3. 只把命中的 20–40 行放进上下文，取完即弃。

### 4. atlas 图集层（可填模板词库）

`master/prompt-atlas.json` 是主文档的**可填槽位视图**（279 个可填叶子、7400+ 枚举选项，中英并列）。主文档 = 原句权威语料；atlas = 可填模板 + 枚举候选词。

| 场景 | 去哪 |
|---|---|
| 知道要哪类词，想扫一遍全部候选、要中英对照 | atlas：`scripts/atlas-lookup.ps1` |
| 要原句、句型、配方、词义解释 | 回主文档：`lookup-master.ps1`（atlas 的 `_ref` 字段给卷号） |
| 详读 atlas 协议与结构索引 | `references/14-prompt-atlas.md` |

```powershell
.\scripts\atlas-lookup.ps1 -Outline                    # 一级分卷总览
.\scripts\atlas-lookup.ps1 -Query "推轨,dolly,环绕"    # 全库模糊搜（多词逗号合并）
.\scripts\atlas-lookup.ps1 -Path "摄影层/焦段镜头"     # 某节点全部叶子（值/_opt/_en/_hint/_ref）
```

## 五、命中失败怎么办（三级兜底）

| 情况 | 处理 |
|---|---|
| 速查卡没有、主文档有 | 正常：回主文档取原句，抄进提示词 |
| 主文档也没有的具名词 | 换成"可验证物理描述"（形/材/光/状态四选二），并在交付里标 `[自创]` |
| 主文档有但语义冲突 | 以**更具体**的那条为准（具名 > 类别 > 泛词） |

## 三、天气与天象

**天气**：`clear 晴（锐利长影）` / `partly cloudy（云影斑块）` / `overcast（均匀漫射、softbox sky）` / `light rain（细斜雨丝+湿面反光）` / `drizzle（玻璃水痕）` / `downpour（雨幕+溅花）` / `thunderstorm（瞬间惨白硬光+紫黑积雨云）` / `snow` / `blizzard（水平雪暴、白茫）` / `fog（轮廓溶解）` / `morning mist（贴地雾带+金色对撞）` / `haze（暖棕空中颗粒）` / `sandstorm（橙色尘幕）` / `typhoon` / `crepuscular god rays（日晕光束）` / `after-rain clearing（洗亮空气+处处反光）`。

**天象（夜空加分项）**：`aurora 绿紫飘动幕帘` / `rainbow 半圆七彩` / `22° solar halo 日晕` / `lunar halo 月晕` / `meteor shower 多条平行光迹` / `blood moon 铜红月面` / `solar eclipse 黑日+日冕环` / `milky way 乳白星云带` / `star trails 同心圆弧`。
> 夜空必配负向：`no light pollution, dark sky`；正向加 `crisp starfield, deep contrast sky`。

## 四、24 个可写时刻（选时刻 = 选情绪）

| 时刻 | 色温 | 光向 | 情绪 |
|---|---|---|---|
| 蓝调时刻 blue hour | 9000–12000K | 柔和无影，城市灯亮、冷暖对撞 | 孤独/神秘/暧昧 |
| 日出 sunrise | 2500–3000K | 最低角度金光横扫、影极长 | 希望/壮阔 |
| 早晨斜光 | 4800K | 明确斜侧、尘埃可见 | 清新/生机 |
| 正午 noon | 5600K | 顶光硬影、眼下阴影 | 焦灼/审判/真相 |
| 下午斜暖 | 5500K 渐落 | 斜侧、影渐长 | 慵懒/怀旧 |
| 黄金时刻 golden hour | 3000–3500K | 低角度暖金、长影、高光低反差 | 温暖/浪漫/史诗 |
| 日落 sunset | 2000–2500K | 贴地平线、最红 | 悲壮/末日 |
| 民用暮光 civil twilight | 冷回升 | 天暖地冷、渐变强烈 | 将变之兆 |
| 夜 fall nightfall | 人工光主导 | 灯光成池、外围冷 | 不安/进入危险 |
| 深夜 late night | 路灯冷白/霓虹紫 | 孤立亮区、湿路反光 | 孤立/内省 |
| 黎明前 predawn | 极冷 | 冷月轮廓+暖路灯对撞 | 不祥 |

**黄金时刻四诀（防 AI 漂到中午）**
1. 写渐变天空：`sunset gradient sky, warm horizon to cool zenith`
2. 写低角度：`sun near horizon, raking side light`
3. **必写影长**：`extremely long shadows`（不写 AI 默认短影）
4. 写冷暖并置：`warm highlights, cool teal shadows`

## 七、场景提示词万能骨架（先框再填）

```
[时代地域]，[视角高度]，
```

## 八、三层纵深制造法（治"平板远景"）

| 层 | 该放什么 | 语法 |
|---|---|---|
| 远景 background | 山势/天际线，低饱、偏蓝、退雾 | `distant layered ridges fading into blue haze` |
| 中景 middleground | 聚落/主体建筑，放主导光，给"节奏与重复"（屋顶成片、塔作轴线） | `a cluster of tiled roofs anchored by a bell tower` |
| 近景 foreground | 压画框的大物件：半开门、垂枝、人物剪影/背影 | `a weathered door ajar in the foreground, a lone figure` |

**四个加深招**：① 大气透视（远蓝近暖）② 引导线（道路/河/廊柱）③ 尺度参照（近处人物让远处建筑显大）④ 冷暖反差（远景冷雾、近景窗暖）。
> 直接抄：`(foreground) mossy stone bridge with a woman leaning on the worn rail; (middleground) whitewashed houses with grey-tiled roofs, faint chimney smoke, warm late-afternoon; (background) layered green hills fading to pale blue mist; the canal recedes as a leading line; golden rim light on the foreground`。

## 九、建筑"叙事破损"（一类选一个，别堆）

| 类 | 触发句 |
|---|---|
| 岁月 | `time-polished door threshold worn into a hollow, handrail polished at mid-section, rain-streak staining` |
| 荒废 | `ivy over the facade, drifted leaves, dust-laden furniture, cobwebs, collapsed roof letting a light shaft in` |
| 战争末世 | `bullet-pocked walls, shell crater, exposed rebar at the broken edge, scorch marks climbing the wall` |
| 失修（有人住） | `peeling plaster curling off, bubbling wallpaper, corroded pipe with rust streaks, warped door stuck ajar` |

配方：`场景 + 破损类(1个) + 破口构件 + 光对破口的反应 + 植物/尘/水的一个反扑`。
> 成品：`an abandoned opera house: peeling gilded plaster, a collapsed ceiling section lets a shaft of light fall across a moth-eaten velvet curtain, moss climbing the marble columns, dust in the beam`

## 十、环境"影"与大气（最容易被忽略的一层）

**影子类型**：`hard cast shadow 硬边投影` / `soft feathered shadow 软羽化` / `long raking shadow 低角度长影` / `dappled shadow 漏光斑驳（树叶/窗格）` / `silhouette 剪影` / `半剪影 rim only` / `reflection 倒影` / `shadow of a second story 影里的第二叙事`。
**光比结构**：`high-key 高调 / low-key 低调 / chiaroscuro 明暗对照 / split 分割 / silhouette contre-jour`。
**大气透视**：`atmospheric perspective, distance desaturates toward blue`；`haze softening the far layers`。
**介质**：`floating dust motes in the beam` / `ground fog below the waist` / `heat shimmer distorting the far view` / `steam venting between the pillars`。

**情绪 × 环境速查**
| 情绪 | 环境配 |
|---|---|
| 孤独 | 大留白 + 小暖源 + 冷场 + 主体占画面 <20% |
| 压迫 | 巨构贴边 + 低机位 + 顶光或底光 + 狭窄负空间 |
| 怀旧 | 暖斜光 + 尘埃 + 旧木 + 轻微褪色 |
| 危险 | 霓虹 + 湿面 + 硬边阴影 + 高频闪烁 |
| 圣洁 | 逆光 + 体积光 + 高调 + 低饱和 |
| 荒诞 | 完美对称 + 平光 + 不合比例的空旷 |

## 十一、户外环境必写清单（三问自检）

1. **天空给了吗**（决定整个画面的色相底）？
2. **三层纵深给了吗**（决定有没有空间）？
3. **空气介质给了吗**（尘/雾/汽/霾——决定"实拍感"）？

三问缺一，画面就会"平、假、干"。

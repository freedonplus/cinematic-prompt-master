# 11 · 六种工作模式 · 十二张配方卡 · 变奏引擎

> 本册解决"同一套公式怎么用出花样"。公式是骨架，模式是姿势，配方是半成品，变奏是同一题的多解。
> **词仍然回 `00-master-index.md` 查主文档**，这里只给骨架与组合法。

---

## 第一部分｜六种工作模式（先判姿势，再动笔）

| 模式 | 触发语 | 输入 | 产出 | 验收 |
|---|---|---|---|---|
| **A 组装** Assembling | "写一条 XX 的提示词" | 一句创意 | 1–3 条完整提示词 + 分栏 | 七层齐、可直接复制 |
| **B 复刻** Remaking | "照这张图/这条片的感觉写" | 参考图/片 + 想改的变量 | 复刻提示词 + 变量标注 | 载体/光位/片质三项与参考同源 |
| **C 延展** Extending | "同一角色/世界观，再来 5 个镜头" | 已有设定块 + 新情境 | 系列镜头表 + 一致性块 | 描述块逐字复用、无漂移 |
| **D 诊断** Diagnosing | "这句为什么 AI 味重/总崩" | 旧提示词 | 病因表 + 重写版（对照） | 每条病灶能指到具体层 |
| **E 取词** Mining | "古风女子发饰都有哪些词" | 一个语义域 | 具名词表（中英 + 适用场景） | 全部来自主文档，标卷号 |
| **F 拆解** Teaching | "这条提示词为什么这么写" | 任意提示词 | 逐层拆解 + 可替换槽位 | 读者能自己套出下一句 |

### 模式选择速判
```
有没有参考素材？ 无 → A（或 E 先取词）
               有 → 想改细节 → B；想扩系列 → C
手上是"写坏了"的稿？ → D
目标是"教会人"而不是"给成品"？ → F
```


## 第三部分｜变奏引擎（同一题的多种解）

### 1. 载体变奏矩阵（同画面 × 6 种介质）

固定 L2–L6 不变，只换 L1 与 L7：

| 编号 | 载体 | L1 换句 | L7 换句 |
|---|---|---|---|
| V1 | 胶片写实 | `Kodak Portra 400, 35mm` | `奶油高光滚降、抬黑、细颗粒` |
| V2 | 数字电影 | `ARRI Alexa, LogC→Rec709` | `宽宽容度、洁净黑场、无颗粒` |
| V3 | 国漫 3D | `Chinese 3D donghua, stylized PBR` | `柔化卡通着色、装饰化轮廓光` |
| V4 | 赛璐璐 2D | `anime cel, flat color, clean lineart` | `平涂 + 硬线 + 网点阴影` |
| V5 | 水墨 | `xuan paper, bleeding ink edges` | `墨分五色、飞白、大量留白` |
| V6 | 黏土定格 | `claymation, fingerprint texture` | `柔边、轻微帧抖、玩具光` |

> 输出花样：一次给 3 个变体（V1/V3/V6），并各写一句"为什么选它"。

### 2. 比例适配矩阵（一张图 → 四种交付）

| 比例 | 改什么 | 注意 |
|---|---|---|
| 9:16 竖 | 改机位为竖构图、压缩横向环境、主体上移留视线空间 | 别只改参数不改构图 |
| 16:9 横 | 加左右环境信息、前景压画框 | 三层纵深更明显 |
| 1:1 方 | 中心构图 / 对称 / 极简 | 砍掉两侧杂物 |
| 2.39:1 宽 | 强调横向引导线与负空间、加 anamorphic 光晕 | 上下要留"电影边"信息 |

### 3. 难度三档（按用户耐心给）

| 档 | 长度 | 给什么 | 用在 |
|---|---|---|---|
| 快写 Quick | 60–120 字 | 五要素核心句（主体+场景+光+镜头+片质） | 随手试、批量抽卡 |
| 精写 Standard | 150–300 字 | 七层齐 + 负面 3 域 | 正式出片 |
| 史诗 Epic | 400–900 字 | 品质锚定 + 大气连贯声明 + 时间戳分镜 + 光影三层 + 收束句 | 广告级、短剧关键镜 |

### 4. 混搭引擎（题材跨界：可混 / 禁混）

| 混法 | 是否可行 | 中介元素（关键） |
|---|---|---|
| 古风 × 赛博 | 可 | `ceramic-plated hanfu, neon piping on the sash, holographic jade pendant` |
| 和风 × 恐怖 | 可 | `shoji screen with a wrong silhouette, tatami stained dark` |
| 港风 × 民国 | 可（近邻） | `neon sign reflected in a qipao's satin` |
| 水墨 × 赛博 | 可（反差） | `ink-wash city dissolving into neon haze` |
| 恐怖 × 卡通 | 禁 | 恐惧依赖真实质感，卡通会消解 |
| 古风 × 现代时装 | 禁（无叙事理由） | 除非做"穿越"设定，需明确叙事语 |
| 写实 × 3D 渲染混写 | 禁 | 一条提示词只允许一个载体 |

### 5. 三条"花样技"（老手常用）

| 技法 | 做法 | 效果 |
|---|---|---|
| **镜像对比** | 同一场景写两版：`A 正常版 / B 反转版`（暖↔冷、静↔动、疏↔密） | 快速定调，交给用户选 |
| **时空换皮** | 固定构图与光位，只换年代/季节/地域三件 | 一个骨架生十个场景 |
| **删减测试** | 逐层删一句，看哪句删了画面就塌——那一句是承重句 | 找到该保留的核心词，避免堆砌 |

## 第四部分｜输出花样（形态选择）

按场景选一种，别混着来。

**统一交付契约（所有形态都遵守）**
1. 先出 `【定妆】` 块（角色/场景一致性锁，逐项写死），再出 `【提示词】` 块；
2. 两块都用 `text` 代码块包裹，块内只放可直接复制的文本；
3. 解释、变体理由写在代码块之外，短句即可。

| 形态 | 长什么样 | 用在哪 |
|---|---|---|
| **分栏式** | `【L1】…【L2】…【成品】` | 默认，验收最清楚 |
| **卡片式** | 一张配方卡：填空 + 光 + 片质 + 变体 | 教人、复用、团队共享 |
| **双栏对照** | 左"原稿"、右"重写"，逐行标病灶 | 模式 D 诊断 |
| **JSON 式** | `{"subject":…,"light":…,"grade":…,"negative":[…]}` | 交给程序批量跑 |
| **剧本式** | 时间戳 + 台词 + 音效分行 | 短剧、多镜成片 |
| **ABC 三变体** | 三个方向各一条，附一句设计意图 | 创意未定、需要用户挑 |
| **速查表** | 只给词表，不给成品句 | 模式 E 取词 |

## 第五部分｜配方卡的维护规则

1. 每张卡只允许一个"主角变量"，其余全部固定 —— 便于对比与复用。
2. 卡里的词必须能在主文档找到出处；新增词要标 `[自创]`。
3. 卡与卡之间不许出现同义混写（`朱红/vermilion/正红` 三选一）。
4. 新卡入库前过一遍 SKILL 的质检清单。
